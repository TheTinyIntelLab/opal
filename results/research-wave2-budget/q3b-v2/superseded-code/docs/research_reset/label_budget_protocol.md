# Q3b: frozen pair-label budgets

This is exposed-source development, prospectively registered before this wave's fitting. It does not supply independent-source confirmation or physical assay savings. Existing Q2/Q3 outcomes motivated this question; their test populations and recipes remain fixed.

On all six Q2 tasks and five original blocks, reserve exactly 4,000 training plus 1,000 validation pair labels (5,000 total), and 16,000 plus 4,000 (20,000 total). Sort full hexadecimal SHA256 of `opal-budget-v1|accession|geneA|geneB` within each original train/validation partition and take its prefix. Smaller sets nest within larger ones. Do not add support edges, replace hard pairs, or access unused pair labels for fitting. Singles, their control measurements and eligibility/count metadata remain available equally to every model; this cost is separate from the pair-label budget. Existing local banks remain exposed development assets.

Define support exclusively from selected training edges. Preserve every original test pair in coverage accounting. All fitted families select and compare on identical training-supported validation and test subsets. Reserved unsupported validation rows remain unused and count against the nominal budget. Unsupported test pairs are abstentions, never silently dropped. Native input contains only training, supported validation and supported test rows; test targets are NaN. Other pair targets never enter fitting. Eligibility metadata is inherited, not newly filtered by outcomes.

Reuse all twelve simple references and fixed rank-eight residual completion (rank 8, penalty .01, 500 Adam .03 steps, seed 20261022, train-only target scale, validation every 25). Select the simple reference on supported validation MSE, with original menu ordering resolving exact ties. Recompute the three original coarse degree/singles/count-stratified shuffled training-residual controls on the selected training graph with seeds 20261023/24/25; at least 80% permutable rows is required. No biology is identified by this negative control alone. Use the pinned native NAIAD revision 9207e9e855e865160a196a6989392f6db622b0d6 with the existing adapter/default capacity, 100 epochs, seed 20261022, batch 1024 and symmetric inference. No architecture, epoch, rank, learning rate or seed search is allowed. Native checkpoints retain original-order validation-min epoch selection. Choose one family by actual symmetric shared-validation MSE, exact ties simple, rank8, native. Save all sixty choices/checkpoint hashes before scoring any new test losses.

The primary candidate is this validation-selected policy. Report fixed rank8 and native as secondary descriptive comparisons. At each budget/task pool the five disjoint original block predictions on the common supported population. Use equal-pair MSE, MAE, bias and Pearson diagnostics, both infection targets, and paired differences against the selected simple policy. Use 2,000 endpoint-multiplicity gene bootstrap draws, seed 20261022, plus leave-one-gene influence; these are conditional sensitivity intervals, not source/culture replication. Task labels do not constitute six independent studies.

A budget qualifies only if every task has at least 90% original-test coverage, at least 50 supported pairs and ten genes, sufficient controls, at least 5% MSE gain versus its selected simple policy, upper conditional gene bound below zero, no worse MSE on either infection target or any of twelve fixed simple references, and strictly better MSE than all three shuffled controls. Choose the smaller passing budget, otherwise no nominee. Completion and native descriptive results cannot rescue a failed selected-policy gate. Full-test zero, additive, minimum and calibrated-singles predictions are diagnostics with the same training labels; calibration has no lookup restriction and cannot hide abstention costs. Report nominal/used training/validation labels and singles/control availability separately. No cross-task mean or p-value is primary.

Freeze code, source banks, original assignments, native checkout/dependencies, this protocol and synthetic tests before profiling/fitting.
