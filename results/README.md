# Release evidence

This directory contains the current growth ledgers, source/protocol records required to interpret them, and v1 validation receipts. The six-task benchmark is in [model-delivery-20261027/benchmark.json](model-delivery-20261027/benchmark.json). It retains the failed Jurkat promotion criterion; [frozen external-transfer results](fitness-external-20261020/results.json) remain unsuccessful.

Older experiments, unsuccessful runs, negative findings and code snapshots are preserved in the [scientific archive](../docs/archive/README.md) with original paths and byte hashes. Restore that archive into a separate source copy before running a historical reproduction workflow. Raw datasets, trained checkpoints and local numerical banks are outside the repository.
