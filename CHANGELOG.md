# Changelog

## 0.1.1, unreleased research preview

Publication is paused. This local revision adopts the requested preprint template, corrects citation metadata and context-transfer scope, defines the released kernels mathematically, moves the final state experiments before discussion, and adds source-generated publication figures. It flattens the repository source into `src/` while preserving the installed `opal` namespace. No saved scientific score is changed. A standalone arXiv source bundle and author-operated submission guide are prepared; no arXiv identifier or public release is claimed.

The private `v0.1.0` tag and draft remain an earlier preparation snapshot. They must not be published as this revision.

## 0.1.0, Opal v1 research release

This freezes the observed-single residual benchmark, exploratory kernel comparisons, independent D-SPIN procedure evaluation, native aggregate CPA/GEARS adaptations, and baseline-only state experiments. Unfavorable and interrupted experiments remain in the evidence record.

The release adds an explicit asset recipe, per-file checksums, source and compact evidence archives, a wheel and source distribution, and Norman and EmeraldBay kernel references. These exports are exploratory development selections, not new confirmatory results. Wessels, D-SPIN, external embedding banks, and native third-party weights aren't redistributed.

The manuscript includes the author's supplied declarations. Software verification establishes execution and restoration, not biological replication or interaction learning.
