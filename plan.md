## Objective and scientific claim

Find the strongest reproducible predictor of genetic perturbation-pair growth outcomes from measured constituent singles and a declared budget of local pair supervision. Compare simple references, completion and distinct interaction architectures under the same information and evaluation contracts. A defensible positive result is the objective, but a failed registered comparison remains a failed comparison.

The initial biological question is assay-local unseen-pair prediction among training-supported genes. Independent-initiation prediction is a separate question that requires evidence of independent biological initiations. Cold-gene prediction, cross-study transfer, expression prediction and biological mechanism require separate evidence and registrations. Predictive residuals alone cannot identify biological interactions.

Success requires a qualified source, an immutable evaluation protocol, superiority under its registered gate, saved predictions and exact replay. Passing software checks or recovering simulated structure does not establish biological usefulness or frontier performance. If the strongest valid comparison favors a simple model, deliver that model and narrow the claim.

## Proposed architecture tournament

All candidates receive identical measured singles, permitted metadata and selected local pair labels. Decompose predictions into a shared main-effect/reference component and any declared residual interaction, so a stronger interaction model cannot obtain a hidden preprocessing advantage. The exact configuration list, tie order and implementation bindings require the four-worker review before freeze.

| ID | Family | Proposed bounded configuration and scientific role |
| --- | --- | --- |
| B0 | Fixed/null references | Zero, TRAIN mean, single sum and single minimum expose trivial and endpoint-specific alternatives. |
| B1 | Calibrated singles | Symmetric sum, absolute difference and product with ridge penalties 1, 10, 100, 1000 supply the historical strong parametric reference. |
| B2 | Gene main effects | Add regularized gene incidence to B1 on the same four penalties to absorb pair-supervised main effects. |
| B3 | Flexible singles | A separately qualified symmetric nonlinear-single reference with and without gene main effects, two fixed penalties, train-only basis and scaling. It must pass prospective replay and accuracy controls without changing historical compatibility. |
| I0 | Current completion reference | Preserve the registered rank-eight assay-local residual recipe as one reference, not a default winner. Use the correct source-local adapter and checkpoint contract. |
| I1 | Explicit pair kernel | A symmetric product kernel over permitted per-gene features with a separate main-effect term and two fixed penalties tests smooth compositional structure without free per-gene latent factors. Bound approximation size from TRAIN metadata before fitting. |
| I2 | Regularized neural composition | One small symmetric main-effect plus pair-interaction network, two fixed regularization settings and fixed epoch/step limits tests a distinct nonlinear composition bias. Reuse qualified native NAIAD where compatible; label any new implementation accurately. |
| I3, conditional | Network or sparse hybrid | Admit at most one additional family only if primary-source evidence, feature parity and pre-outcome profiling justify it. Otherwise retain its written rejection reason and omit it before freeze. |

No unrestricted rank, width, seed, epoch, penalty or feature sweep is allowed. I0, I1 and I2 share the validation-selected main-effect policy when mathematically compatible; any jointly fitted variant is a separately declared configuration charged to its family's cap. B3's exact two penalties, kernel basis, I1 kernel and I2 architecture must be specified numerically in the frozen registration, not filled in after evaluation results.

Each learned family receives at most four substantive configurations, with the explicitly listed historical B1/B2 grids retained. Optimization randomness uses one frozen fit seed per cell; three evaluation data seeds measure generator variability rather than selecting a favorable optimization seed. Validation selects configurations and one deployed policy with deterministic complexity-first ties. Save and report every fixed family alongside that policy, so a failed selector cannot be rescued by choosing a TEST winner.

An uncertainty wrapper is fitted/calibrated using TRAIN/VALIDATION only and applied consistently across families. Register support/degree and input-shift abstention rules, coverage-risk reporting and calibration diagnostics. Do not claim distribution-free or out-of-distribution coverage from dependent pair data without the required assumptions. Separate rejection for missing support from a calibrated uncertainty decision.
