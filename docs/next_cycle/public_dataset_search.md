## Exposure and permitted interpretation

Published narrative results were encountered during source discovery. A search-engine result for GSM3358488 also incidentally displayed 20 RMA expression values. That incidental exposure is recorded in the retrieval artifact; no quantitative comparison or fitting followed it. Combi-seq expression outcomes remain unopened. New candidates must not be described as wholly outcome-unseen without this qualification.

Public availability supports downloading and investigating a diagnostic source within its documented scope. A missing explicit derivative-redistribution statement should be tracked separately from scientific suitability; it is not evidence that the owner must obtain the original public files manually. Release redistribution still needs its own source-specific review. None of these datasets supplies an externally timestamped registration or separate confirmation custody automatically.

No software or biological gate was weakened to admit these candidates. A rat microarray diagnostic or small HepG2 diagnostic would require a recorded source-specific contract and endpoint before opening the response matrix. The current release remains the previously tested package; this metadata audit does not claim a new biological run, new package build or completed confirmation study.
