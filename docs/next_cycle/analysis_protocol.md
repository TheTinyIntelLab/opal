# Fixed-state analysis protocol, version 1

This is a runnable draft, not a public registration or a claim that any source has passed. No new architecture search is authorized by this protocol. A source must qualify before scientific fitting; Combi-seq currently does not. Synthetic engineering and exposed-development rehearsal are explicitly separate roles.

## Data and custody

Use one state, assay, modality, endpoint and exact dose assignment. Retain every required metadata field from `opal.replicated.contracts.REQUIRED`. Unknown initiation evidence stays null. A culture evidence object must identify `kind: independent_initiation`, its `culture_id`, primary `record_id` and `source`; a run/plate label or unstructured assertion is insufficient. The schema can check consistency, but primary provenance still needs a custodian review.

Canonical global pair IDs group every dose, state, reagent variant and culture of the same aliased unordered components. Canonical condition IDs preserve component-specific dose, unit and reagent assignments. Exact controls and singles match study, source, culture, state, assay, control stratum and time. Sequential interventions and repeated targets need separate contracts. Profiles in prepared banks follow canonical component order.

Alias chains resolve to their final identity in both grouping and profile ordering; cycles fail. Frozen gene diagnostics use equal-culture/equal-pair weights so duplicating a technical row cannot redefine the signal panel. Independent-reference accounting and norm/alignment diagnostics retain that aggregation rule.

The analyst receives development responses, allowed query controls/singles, and query metadata. Query pair outcomes stay on separate custodian storage. A directory under the same unrestricted account does not provide secure custody. The query adapter rejects pair response rows, and the typed query bank rejects unexpected fields that could conceal outcomes.

The aggregate adapter normalizes each count row to a frozen library target, averages matched references, then transforms with log2 and a frozen positive pseudocount. The draft target is 10,000 with pseudocount one; these are explicit configuration choices awaiting assay qualification. Preserve source count files, their hashes and mapping metadata. Freeze the output gene order from allowed development/reference information; every evaluator checks genes, scale and units exactly. Do not apply historical single-cell QC thresholds to aggregate reads.

## Split and candidate selection

Construct one seeded, metadata-only, degree-balanced split of global pair identities. Register actual training/validation/test counts after graph and precision qualification; no response-driven redraw is permitted. Confirmation cultures must be disjoint from development. Every response-consuming stage is checked against global held pairs, confirmation cultures and guard rows, including preprocessing, calibration and pretraining.

The finite menu has 16 configurations: additive plus three penalties each for shared offset, global linear profile correction, summed-single kernel, component-additive incidence, and global-plus-pair-product kernel. All use the same registered inputs. The incidence model has a centered, regularized intercept/component constraint and zero component correction for unsupported targets. It contains no target-factor product. The row-reference kernel reuses the established symmetric global/sum/product algebra while retaining culture-specific measured singles; fitted scales and reference bandwidth come from development only.

Select the strongest eligible non-product reference and the pair candidate using equal-culture/equal-pair validation MSE, then lexical configuration ID for exact ties. Refit on training plus validation in development cultures. Freeze family-specific references as secondary comparisons without promoting a test-best replacement. Three registered profile-shuffle seeds repeat the same menu and budget, permuting complete profiles within culture while preserving gene coordinates and shared references. A separate incidence placebo permutes training pair assignments; consistent global identity renaming is not treated as a negative control.

## Metrics, inference and decisions

The primary metric is equal-culture, equal-canonical-pair, equal-gene MSE. Collapse technical occurrences within each culture/pair block, reject incomplete blocks, and retain every condition exclusion. The narrow population is the fixed registered held-pair panel in new independent cultures of the same state. Paired Student t intervals use culture-mean error differences, requiring at least three cultures, and remain subject to empirical coverage qualification. They do not support unseen-target-panel inference. The reported scaled gain interval divides difference endpoints by the observed reference loss; it is labeled as such rather than claimed as an exact ratio interval.

The default gate requires at least 5% point MSE gain over the selected strong reference, a positive lower paired 95% difference bound, improvement over additivity, a positive aligned-versus-shuffled contrast, and qualified measurement/attribution. A positive lower bound does not establish a true gain above 5%. A narrow upper bound below the materiality threshold is precise failure; a wide crossing interval is inconclusive.

MAE, a strongest-response development gene panel covering 10% of genes, normalized development squared-response weights, residual alignment and norm error are frozen diagnostics. They cannot rescue a failed primary. All selected family comparisons, additive and shuffled/placebo controls remain in the report. Independent-reference main/residual/cross-term accounting is calculated only when separately measured evaluator references exist; same-anchor residual loss is explicitly identical to response loss.

Development repeated-pair diagnostics leave the evaluated culture out of the shared correction and retain their forbidden-information status. Technical halves estimate technical sensitivity, not biological reliability. Whole control/single draws must be reused across all affected pairs. The read-count allocation command separately thins controls, singles and pairs with fixed validation IDs; it is a technical read-sampling model, not biological variance.

The empirical power command resamples entire development culture error blocks for a fixed fitted predictor, preserving within-culture pair/component/shared-reference dependence. It reports null false-positive calibration, positive-gain detection and point-plus-interval gate probability at 2%, 5%, 7.5% and 10%, plus inflated variance sensitivities. The separate `procedure-power` command resamples whole development-culture outcome/reference blocks, varies culture counts and pair density, and repeats the entire finite-menu selection, refit and shuffle procedure. It generates simulated held outcomes only after selection using a conditional calibrated local alternative, retains infeasible alternatives as failures, and reports exact binomial Monte Carlo intervals. It cannot extrapolate a new target population; biological design qualification still requires an accepted empirical pilot and statistical coverage review. Hypothetical or synthetic outputs never qualify a biological design.

## Executable sequence

Run `python tools/run_replicated_fixed_state.py --help` for exact arguments. Every command uses a new output path.

1. `qualify` checks full row metadata and exact matched reference support; `split` constructs a deterministic global partition and graph-support manifest.
2. `prepare` creates a development-only aggregate-read bank; `query-references` creates a reference-only query bank from separate query identities. Preserve both original inputs and preparation manifests. `prepare-sealed` is a custodian-only command on separate storage; never send its bank to the analyst.
3. `diagnose` runs development-only metric controls, shared-correction cross-fitting, reliability where cultures exist, and one target-balanced coverage curve. `allocation` runs technical read-count allocation on allowed original development counts.
4. `power` consumes empirical `reference_errors` and `candidate_errors` as culture-by-pair arrays. `procedure-power` consumes a development-only prepared pilot, protocol and design JSON; it repeats selection for each simulated study. Neither synthetic demonstration qualifies the biological design. `quote` expands registered design quantities against source-dated item prices, leaving unavailable prices null. `protocol-check` validates the protocol before freezing.
5. `freeze` checks metadata/access/schema, selects/refits the finite menu and saves predictions, selected families, fitted state, shuffles, access log, code/input hashes and immutable prediction manifest.
6. The custodian invokes `evaluate` with the frozen directory and a separate outcome NPZ. It rejects changed hashes, membership, culture IDs, genes, units or scale and accepts one score record per freeze. `restore_predictions` verifies checkpoint restoration without response access.
7. The report emits all registered comparisons and the prespecified branch. `opal.replicated.diagnostics.interpret` also maps measurement failure, component-only benefit, main-reference repair, secondary-only benefit, state-transfer failure and precision limitations to section 18 actions.

For an engineering check, run `python tools/run_replicated_fixed_state.py demo --output tmp/replicated-demo-new`. This creates synthetic data, diagnostics, illustrative power, a frozen checkpoint and a scored report; its data role prevents scientific advancement.

## Registration and amendments

Before real confirmation, replace draft fields with the accepted source, precise biological-unit allocation, exclusion policy, gene schema, endpoint qualification, approved interval/power method, final sample size, budget, stopping rule and custodian. Use an actual timestamped OSF registration or equivalent registration service, disclose prior exposure, and retain its real URL/receipt. A local hash does not establish public timing. Scientific evaluation requires a registered protocol role and review evidence tied to the freeze hash.

The custodian evidence JSON must include `registration` with `verified: true`, the exact protocol `url`, a timezone-aware `registered_utc` no later than the freeze, and a nonempty `verification_source`. This records a custodian review rather than automatically verifying an external service. A URL in a protocol never establishes registration by itself. Restoration requires the original query-reference bytes and exact pair/culture membership. The evaluator exclusively creates its receipt before publishing a report; interrupted report writes retain their attempted-score receipt for review.

Preserve every original protocol, prediction freeze and score. Record any defect's timing and outcome exposure before an amendment. A corrected exposed test is retrospective; material changes need fresh confirmation. No messages, purchases, public uploads, DOI creation or arXiv submissions are performed by these commands.

Scientific protocols require `statistical_design` with empirical pilot and interval-coverage report SHA-256 hashes, review source, allocation matching the actual confirmation cultures, fixed-panel estimand and no-peeking stopping rule. Backing JSON reports must exist and declare independent-culture verification and accepted fixed-panel qualification; declarations remain subject to custodian review. The default runner budget is 2 GiB peak process memory and its registered wall-clock limit; an unavailable peak measurement cannot satisfy a scientific memory budget.

`processing_diagnostic` and `registered_processing_secondary` permit within-run development/query culture overlap while preserving global held-pair isolation and exact reference matching. Their intervals are descriptive processing-repeat intervals and cannot pass the primary biological advancement gate. `amendment` preserves original and replacement hashes, affected inputs, reason and exposure timing; outcome-exposed corrections require fresh confirmation.

The evaluator emits fixed-prediction leave-one-culture and leave-one-component deletion sensitivities. All pairs involving the deleted component are removed symmetrically, and technical repeats collapse before aggregation. A component-deleted panel changes the diagnostic estimand; it cannot support unseen-target generalization or replace the primary report. With fewer than three remaining cultures, only descriptive point losses are reported. Processing scopes remain descriptive. Preparation CLI metadata access checks run before any count archive is opened, and existing preparation sidecars are preserved.

Run `python tools/rehearse_replicated_assay.py --output tmp/assay-rehearsal-new` to exercise the count-based CLI route, including separate analyst/reference/custodian artifacts and exact reference-lineage checks. The generator is synthetic and cannot establish independent biological units or secure storage. Read-allocation metadata checks precede count archive access.
