# Author-hosted combinatorial source metadata

The public [PertSpectra repository](https://github.com/insitro/PertSpectra/tree/main/data/inhouse) supplies its NF-kB combinatorial data directly through S3. The new bounded HTTP-range reader resolves observation metadata inside the 3,142,132,144-byte H5AD without decoding expression datasets, embeddings, clusters, expression-derived archetypes or model weights. It checks each response's range and object ETag, caps total retrieval at 32 MB and rejects servers that return the full object. Cached blocks may contain adjacent uninterpreted expression bytes, so this is selected metadata decoding rather than a claim that no source bytes associated with expression were received.

The initial schema audit read only the predeclared treatment column. A second scope added the actual sample and target-assignment fields found in that schema, and a third scope added their cross-tabulation. Each scope remains preserved. The final audit received 1,245,184 bytes across nineteen ranges. The [report](../../results/replicated_fixed_state_v1/pertspectra-obs-metadata-20261010-v3/report.json) identifies 73,015 deposited rows, compared with 65,648 filtered cells described in the paper; this review does not reconcile the authors' filtering pipeline.

There are eight SampleIndex labels, each associated with one TNF context. Labels 1, 2, 4 and 8 are TNFA-negative; labels 3, 5, 6 and 7 are TNFA-positive. Each stratum has thirty literal single-target labels excluding intergenic targets and 264–269 literal distinct two-target labels with both single labels present. Repeated-target and intergenic assignments remain distinct. The deposited target and guide-call labels each have only one or two components; no higher-order assignment is established by this audit. These counts refer to observed labels, not accepted canonical perturbation identities or sufficient cells for an endpoint.

This resolves a useful broad-panel lead, but [qualification remains incomplete](../../results/replicated_fixed_state_v1/pertspectra-obs-metadata-20261010-v3/qualification_decision.json): SampleIndex does not verify independent initiation, the two contexts cannot be combined to claim eight same-state replicates, and literal gene labels do not establish matching guide/reagent references. The expression body was not decoded and no prediction model was fit. Independent local HDF5 parsing reproduces all selected metadata counts and strata exactly from hash-checked cached ranges with zero network requests. Tests cover ignored ranges, changed object identity, byte budgets, cross-block caching and context-specific single support.

The search also followed the [CINEMA-OT primary paper](https://www.nature.com/articles/s41592-023-02040-5) to its [public Dryad deposit](https://datadryad.org/dataset/doi:10.5061/dryad.4xgxd25g1). It supplies three donors across day-two and day-seven stimulation, with three IFN-beta-centered cytokine pairs. The six donor/day files are not six independent same-state biological units. Public data availability is verified through the deposit and author README, but no archive, raw matrix or processed expression file was opened. Its [decision](../../results/replicated_fixed_state_v1/dryad-cinemaot-metadata-20261010-v1/qualification_decision.json) distinguishes this primary-design review from a sample-level matrix audit.

Neither source passes the original confirmation gate. Both preserve concrete routes for later external-development diagnostics under an explicit contract, rather than substituting cells, technical labels or durations for independent cultures.
