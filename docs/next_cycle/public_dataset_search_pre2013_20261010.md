# Pre-2013 source qualification continuation

The new [date-bounded query configuration](../../configs/datasets/public-discovery-pre2013-20261010.json) retrieves 172 GEO series, all absent from the preceding summary inventories. Their union now contains 1,048 distinct series identities, with sixteen repeated records across searches. The new [coverage tool](../../tools/summarize_source_search.py) reproduces that count from source-hashed inventories, retains overlap and changed summary hashes, and explicitly performs no biological qualification. Each query remains capped at 150 records, so the union is not an exhaustive historical search or a count of deeply reviewed sources.

Eight sources received sample-level review through sixteen successful brief-metadata requests. All twenty-seven new discovery and brief snapshots pass byte-count and SHA-256 verification. The [decisions](../../results/replicated_fixed_state_v1/public-pre2013-followup-20261010-v1/qualification_decisions.json), [sample counts](../../results/replicated_fixed_state_v1/public-pre2013-followup-20261010-v1/sample_audit.json) and [verification](../../results/replicated_fixed_state_v1/public-pre2013-followup-20261010-v1/verification.json) preserve the evidence without storing raw contact-bearing metadata in Git.

GSE2350 illustrates why a six-repeat description needs sample-level inspection. Its 387-record series contains a 24-array Ramos BCR/CD40 panel, GSM44051 through GSM44074. Each arm contains three records from clone 1 and three from clone 2, so pooling them mixes clone states. The [primary CD40 paper](https://ashpublications.org/blood/article/104/13/4088/18960/Tracking-CD40-signaling-during-germinal-center) reports six independent experiments for its CD40 comparison; this does not establish six matched same-clone initiation blocks for all four deposited arms. The nominal graph has one pair, and the brief sample records do not resolve doses or duration. This review encountered published descriptions but opened no expression table or matrix.

GSE26599 reports five independent experiments per arm in each of three breast cell lines. Its repeat labels are 1, 2, 3, 4 and 6, which must not become six experiments. Series and sample protocols also disagree on dose notation and control/joint abbreviations. GSE21571 provides three reported independent repeats for three yeast gene pairs; GSE30492 provides four pooled plant-tissue repeats for one pair. These are source-specific leads, with different unit and state contracts.

GSE35218 lacks constituent expression singles, and its companion GSE35506 measures methylation. GSE38132 has quadruplicate hormone groups whose shared protocol omits several titled treatments. GSE34672 has three records per chemical arm in each of two lines, plus a distinct shRNA comparison. None supplies the original qualified independent-culture bank. No additional expression outcomes were consumed, and no architecture or configuration search was introduced.

The preceding `ae76a96` implementation passed all four Windows/Linux Python 3.11/3.14 CI jobs, including fresh CPU dependency installation, saved-query restoration and the synthetic assay route. The new coverage tool is tested for overlapping identities, changed summaries, duplicate records, incorrect counts and expression-access flags; it is included in the same CI matrix. Original biological confirmation and empirical precision remain incomplete.

Full local verification: 234 tests pass, including the new source-identity coverage tests.
