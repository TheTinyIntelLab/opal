# Replicated observed-single prediction: collaboration brief

Opal predicts a pair's population-mean response from matched measured singles. Its existing comparative study finds strong simple corrections and unresolved incremental pair value. We seek provenance and access to an existing replicated transcriptomic pair screen before proposing new laboratory work.

Two questions must stay separate: do departures from a strong shared correction reproduce in independent cultures, and can a frozen allowed-input predictor recover those departures for globally held pair identities? The current Combi-seq metadata provides promising coverage, but run labels and identity-matched singles do not settle independent initiation or exact doses.

## Specific provenance request

1. Did rep1, rep2 and rep3 begin with independently initiated cultures? Please map initiation, passage/source material, reagent preparation, harvest and processing to each run, including shared stocks and lots.
2. What exact component dose, vehicle, order and treatment endpoint corresponds to every treatment barcode and its monotherapies? How should reversed barcode variants and the additional DMSO control be handled?
3. Which counts, gene annotations and processing revisions are authoritative? Are treatment-barcode read totals the intended aggregate assay unit, and what assignment/QC information is retained?
4. May a custodian supply development outcomes, allowed query controls/singles and metadata while withholding globally held pair outcomes on separate storage? What prior numerical outcomes have participants already inspected?
5. What terms allow research reuse, metadata release, prepared aggregate banks and fitted exports separately?

Opal contributes metadata qualification, assay preparation, bounded shared/component/pair references, development-only metric diagnostics, empirical precision analysis, immutable prediction hashes and an evaluator package. We would report favorable, unfavorable, interrupted and amended outcomes with the same evidence record. We do not require a new assay purchase to finish the current software release.

If existing data qualify, start with a registered secondary analysis. If new cultures are needed, compare an established bulk-RNA assay, targeted panel and the collaborator's current single-cell platform using an itemized quote. A 12-intervention complete panel has 66 distinct pairs, 12 singles and a control per culture, before technical/reagent/layout additions; its power is not yet established.

## Agreement before exchange

Record data ownership, allowed derivatives, outcome custody, amendment/exclusion authority, expected contributions and authorship based on actual work, adverse-result reporting, storage, and release scope. Ask a statistical genomics reviewer to assess culture-level inference and empirical null coverage before registration. Contact identification and messages, assay commissioning, expenditure and commitments remain owner actions; this brief has not been sent.
