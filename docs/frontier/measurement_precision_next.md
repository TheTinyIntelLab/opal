# Next objective: independently measured contrast precision

This is a proposed nonquery measurement design, not a registered or commissioned assay. No culture, partner, reagent choice, useful margin, power or price is certified by this document. The root `plan.md` selects this as the primary next objective because current prediction probes fail strong controls and GxE residual disagreement can be dominated by single/control precision.

## Hypothesis and estimand

For one assay and a literal, matched intervention panel, the context difference in pair residual response contains repeatable pair-specific variation across independently initiated cultures beyond shared offset, scalar affine calibration and component-incidence effects. Estimate culture-level contrast covariance and independent-reference disagreement, retaining full-response MSE and support as descriptive secondary endpoints. Technical sampling variability and biological covariance must be reported separately; neither provides an automatic molecular mechanism claim.

Use a completely connected six-intervention, fifteen-pair panel in two pretreatment-defined contexts. This is a small measurement pilot, not the frozen >=36-pair diagnostic or a new transfer benchmark. Review reagent, dose, timing, simultaneous/sequential status, vehicle and assay compatibility before choosing identities. Three independent cultures per context is an administrative identifiability starting point, not a power calculation or an approved culture count. A biological reviewer must change or accept that count before any outcome access, using an externally justified useful margin and a documented budget. If the required precision is unaffordable, do not commission the pilot.

Each culture has two separately initiated/measured control-plus-six-single reference sets. Pair outcomes are measured once under a separate recorded matching lineage; both reference-role comparisons use the identical pair outcome. Randomize treatments within culture/block and record initiation IDs, dates, passages, plates, wells, aliquots and exclusions. The illustrative ledger is `15 + 2*(6+1) = 29` assay outcomes per culture, or 174 for six cultures, before failures, extra dose/vehicle groups, technical repeats, pilot costs and sequencing. These are proposed counts, not acquired data or prices. Costs require actual written quotes.

## Records and analysis frozen before outcomes

Required records are original assay SOP, literal reagent/guide-equivalence map where applicable, exact units/time/vehicles, culture-initiation lineage, pretreatment context definition, randomized allocation, sample-to-count correspondence, independent reference matching, QC/support thresholds, research/export rights and all resource/assay costs. Retain complete normalized pair/single/control aggregates for each culture/stratum/reference role, their axes, count denominators, source/code/config hashes and every exclusion. Do not reuse exposed GxE cells as independent cultures or reuse pilot outcomes as final confirmation queries.

Freeze pilot identities apart from any confirmation population. Split by independent culture/block, keep all outcomes from a culture together, and estimate nuisance corrections on other cultures and prespecified pair groups. Use shared-offset, affine and component-incidence adjustments with identical reference access. Compare unadjusted and adjusted repeatability; compare the two independent-reference roles on identical supported pair outcomes. No phi18 or rank-16 head selection occurs in this precision pilot. Pair-identity resampling alone is insufficient; uncertainty must reflect independent culture and shared-reference covariance. With the small proposed culture count, asymptotic intervals are not assumed calibrated. Review a finite-sample null/type-I and interval-coverage design before treating a biological bound as valid.

The reviewer freezes a meaningful contrast precision margin from biological utility, the maximum missing/support fraction, covariance estimator, confidence level, coverage/power target and finite extension limit before observations. These values are intentionally unset. No binary biological gate is evaluable until they are supplied, evidenced and reviewed. Merely labeling a JSON file approved does not satisfy the requirement.

## Promotion, redesign and termination

Proceed toward a new prediction registration only if complete source compatibility and culture independence are established, independent-reference measurement error is below the reviewed useful-margin envelope, and a calibrated culture-level lower bound supports repeatable adjusted contrast beyond its reviewed threshold. This permits designing a separate finite predictive comparison; it does not nominate a model. The comparison must retain matched mean/context/calibration/incidence/kernel references, globally excluded pair identities, source-only selection, sealed predictions and independent final culture/context evaluation. Fresh confirmation requires a separately powered registration and complete inference-resource accounting.

If reference noise explains the contrast and a quoted increase in reference precision can meet the frozen margin, redesign measurement once within the predeclared extension budget. If precision is adequate but the calibrated upper bound excludes the minimum useful repeatable signal, retire this pair/context formulation for the tested assay/population. If bounds are inconclusive, use only the predeclared extension; if that cannot resolve precision within cost, stop. Missing provenance or rights means no-go, not a biological negative.

## Resources and responsibilities

Local software preparation/review may use the existing environment with one thread, no GPU/installation/acquisition and at most 300 CPU seconds, 1 GB sampled RSS, 10 MB retained audit receipts and a 1 GiB writable reserve. Actual assay processing cannot inherit these limits. A future numerical envelope must include the real count-file sizes, transient allocations, aggregate retention, every fit/reference, scratch and failure reserves, continuous peak profiling and interruption recovery. The current 25 MB pair proposal is inadequate even for its 55,148,544 uncompressed prediction bytes. The 47.8 GB checkpoint upper estimate exceeds the present approximately 14.5 GB C: free space, but remains unprofiled; feasibility is unestablished rather than disproven for all implementations.

The owner supplies actual operation acceptance if a new run is proposed. The biological reviewer supplies protocol, margin/power and lineage review. A real partner supplies cultures and measurements. Rights holders supply relevant permissions. No one is impersonated, no message is sent, and no assay is ordered here. The exact request checklist is `measurement_records_request.md`; completion means receipt of the actual records and measurements, not completion of this draft.
