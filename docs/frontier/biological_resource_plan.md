## Smallest acceptable alternatives

The prior proposal for a longer measurement envelope was not needed. C-parser optimization and tiled reference computation completed exact recovery and panel reproduction inside the original envelope. A future different boundary would require its own genuine acceptance. A checkpointed/chunked design could bound each job's CPU but needs a reviewed retained-state budget; partial cell totals/selected coordinates cannot be discarded between jobs. Streaming one incomplete prefix cannot recover full-library denominators or exact final metrics. Reducing genes, dropping unsupported groups, changing normalization, or accepting only favorable pairs would change the scientific replay and is not an acceptable recovery shortcut.

Do not rerun the 53,280-fit procedure in order to profile storage while source-ineligible. After source qualification, profile a small fixture's full state layout, then budget the exact full schedule without omitting nested failures or comparator states. Request additional storage/budget only if measured capacity is insufficient and a genuine scientific go decision exists. Current capacity establishes neither an available 47.8 GB reserve nor impossibility under all future profiled implementations.

The frozen reconstruction-v1 runner always uses its recorded 300-second configuration. A longer operation needs a separately identified operational version that consumes the supplied acceptance and enforces CPU/wall/finalization limits; editing the failed v1 configuration is prohibited. The separately identified version-2 executor is now implemented, tested and successfully run with the unchanged 300-second CPU ceiling; no executor prerequisite remains for this closed workstream.
