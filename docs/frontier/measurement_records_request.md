# Measurement records needed to finish the scientific plan

The owner has authorized execution. The repository now contains working software, actual single-response results and the official GxE measurement inputs. What remains missing is experimental provenance and a genuinely independent confirmation panel. This packet identifies the source records needed; it is a draft, not a sent message, collaboration agreement or laboratory order.

## PertSpectra inhouse source

The existing public cache and archive contain counts and observation labels, but no separate exact protocol/guide-equivalence records. Request the assignment table mapping each `SampleIndex`/treatment/`feature_call` to actual guide/vector sequences, validated single/pair reagent equivalence, treatment and stimulation dose/units/duration, simultaneous/sequential initiation, assay/library IDs and exact vehicle/control matching. Preserve every ambiguous guide mixture rather than assigning equivalence from gene names. Independent culture IDs, initiation dates/provenance and source-reference lineage are needed for biological interpretation. This source still must satisfy the unchanged 36-pair/256-gene contract; another source cannot replace its frozen identities without a separate registration.

The original source identifiers are [the author repository](https://github.com/insitro/PertSpectra) and [the data deposit](https://zenodo.org/records/18180141). The raw cache hash is recorded in the source qualification receipts. No dose, initiation or guide-equivalence statement is supplied by this request.

## sci-Plex-GxE public source

The official [GSM7056151](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM7056151) counts, annotations, hash table and sample sheet are acquired. The [author methods](https://cole-trapnell-lab.github.io/pdfs/papers/mcfaline-sci-plex-gxe.pdf) document dose/time/vehicle and RT cell-origin allocation. The [pinned processing code](https://github.com/cole-trapnell-lab/sci-Plex-GxE/tree/63eed120697611d8baf4a207a797a147308a6674) supplies additional assignment rules.

Request the explicit field schema for the deposited hash table, unique physical well IDs behind repeated hash labels, the original plate map with seeding/handling provenance, independently initiated culture IDs/dates, and an explanation of inconsistent nominal replicate labels within plates. Ask for a treatment-to-catalogue/lot mapping and permission terms covering aggregate exports or fitted reference assets. Keep the published article licence, repository code licence and measurement/export permissions separate. An independent reviewer must assess whether any repeats satisfy the intended culture estimand; the code cannot decide this from a `rep1` suffix.

This source has only a trametinib star, not a broad crossed pair graph or genetic TNF assay. Its technical pilot cannot confirm the earlier predictor or satisfy the 36-pair diagnostic floor by counting doses or repeats as new pair identities. Its three measured cell origins do not supply three source plus two independently held contexts by relabeling cells.

## Prospective partner panel

Use [the crossed-repeatability pilot specification](crossed_repeatability_pilot.md) and the successor readiness schema. The partner must provide actual literal assignments, independently initiated cultures, randomized blocks and independently estimated control/single references before numerical confirmation. A separate empirical pilot and biological reviewer must set useful margin, culture count by context, power/coverage criteria and actual assay cost. Globally frozen nonquery pilot/source/bridge identities must remain separate from fresh query outcomes.

No existing failed predictor is automatically nominated for this panel. A kernel or simpler reference can become the successor if independently validated under the exact contract. Fresh measurements must test the precise capability and information budget; assay-saving claims also need the blinded functional/campaign outcome and complete cost ledger. No useful margin, powered sample size, laboratory price, partner or confirmation result is fabricated here.
