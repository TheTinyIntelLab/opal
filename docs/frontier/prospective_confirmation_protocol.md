# Prospective independent-culture accuracy confirmation

Draft for review, not an executable registration, commissioned experiment or evidence of collaboration. No candidate is nominated. The finite rank-16 probe remains closed, and the frozen TNF context-contrast diagnostic remains source-ineligible. This protocol describes the narrow confirmation claim that could become justified after a useful source-only nomination and independent reference/culture precision evidence.

## Claim, endpoint and independent unit

Test whether one nominated and frozen Opal procedure predicts mean transcriptomic responses in fresh independently initiated cultures more accurately than a strong, source-locked same-information comparator, by a reviewed useful absolute MSE margin in each of two prespecified, already observed pretreatment contexts. Both contexts are represented in source selection. This is independent-culture predictive accuracy, conditional on measured query singles/controls and fixed interventions. It does not test transfer to unseen contexts, causal interaction recovery, mechanism, or prospective assay savings. Generalization to unobserved pair identities would require a separate globally excluded pair-identity design and explicit exposure audit; previously exposed identities cannot earn that claim here.

For context c and independent block j, define each method's loss as gene-mean squared full-response error averaged equally over the fixed eligible query pairs. Define `D_cj = L_baseline,cj - L_Opal,cj`. The primary estimand is `E[D_cj]` separately in both contexts, conditional on the registered pair/gene population and source-trained procedure. The independent experimental unit is a complete culture/reference block, not a cell, gene, pair, well or computational seed. Pair-identity variability is a secondary target-population sensitivity, not extra independent cultures.

An independent initiation has a distinct recorded culture initiation, date and lineage from the common permitted stock, rather than an aliquot of the same initiated culture. Common stock/genotype remains a population restriction. A block contains one pair-outcome culture C and two independently initiated reference cultures R_A/R_B, matched on pretreatment context, passage policy and assay timing, with lineage and contamination/viability records. Blocks share neither initiated cultures nor reference cultures. Temporal/plate batches are randomized/balanced and retained as design blocks. If nominal blocks share an initiation, combine them into one dependence unit before any inferential analysis; do not inflate n.

## Measurement design and assignments

The illustrative panel contains six reviewed interventions and fifteen distinct pairs, with matched dose, duration, vehicle, assay and simultaneous/sequential initiation. Actual identities and biological utility remain unset. Each C culture supplies fifteen pair outcomes and its own vehicle outcome; each R culture supplies six singles plus vehicle. This is **30 measured condition outcomes per independent block**, requiring **three independent culture initiations**. Two contexts with n blocks each require `60*n` measured condition outcomes and `6*n` initiations before failures, technical repeats, additional matching groups, sequencing or functional assays. At the administrative n=3 this is 180 outcomes and 18 initiations, not a powered recommendation. Earlier 29-outcome sketches lacked the separately matched pair-culture vehicle and did not fully distinguish reference initiations; they remain historical drafts.

The measured pair response is normalized using its own C control; reference A supplies permitted query single/control features. Reference B is a prespecified sensitivity role swap using the same pair outcome and C control. Roles are fixed before processing. This separates reference noise from evaluation-control noise without treating role swaps as independent replicates. A biological reviewer must verify that independently initiated reference means are compatible with the intended prediction endpoint; if the assay requires same-culture matching, use a new reviewed estimand and retain the resulting covariance rather than asserting independence.

Record intervention/reagent/guide identity and lot, guide-equivalence validation if relevant, physical dose/unit, duration/unit, vehicle, assay, context freeze, initiation/parent IDs, passage, randomized treatment/well/plate/block and sample-to-count mapping. Pre-register viability, assay, count/library and matching-support QC from a nonquery pilot. All eligible declared pair/block outcomes must be accounted for. No response-selected genes, post-treatment context labels, favorable missing-row deletion or outcome-driven exclusions are allowed.

QC reviewers are blinded to model identity and paired improvement. Distinguish failed biology, technical failure, missing matching controls and missing labels. Report the whole declared and supported population. A model failure receives its locked comparator prediction on the same supported measurement rows and blocks success; missing truth is never assigned zero error. The maximum tolerated missing block/stratum fraction and any bounded replacement rule must be reviewed before data. If complete-support requirements cannot be met, the primary result is inconclusive, not a supported-subset success.

## Comparators, information and freeze

Nominate exactly one procedure only from permitted source outcomes, using nested source-only tuning. Freeze its full code, configuration, gene/condition axes, scalers, bases, banks, hyperparameters, source hashes, exposure history and fallback rules. The main comparator is a locked source-selected strong reference among fold-refitted Base, calibration/offset, component-incidence, capacity-matched mean/context and pooled/per-context/joint-context kernels as applicable to the new task. Include additivity/no-change and matched alignment controls as diagnostics. Each receives identical source labels, query reference sets and calibration opportunities, with complete tuning/resource accounting. Historical weights, incompatible assays and outcome-selected gene panels cannot be silently substituted.

A data custodian separates fresh pair evaluators from training/reference roles. Candidate and comparators receive no confirmation pair outcome, QC statistic derived from prediction error or evaluator path. Hash and independently timestamp all predictions, all inference dependencies and complete expected row identities before the custodian releases evaluator outcomes. Verify saved-state replay, query mutation, row identity and full fallback accounting first. No tuning, dose/rank rescue, baseline reselection or extra endpoint follows unblinding. The current automatic-acceptance wrappers cannot supply the needed owner acceptance or reviewer attestations.

## Useful margin, power and inference

The biological collaborator must set a positive absolute MSE margin delta from a defensible utility/assay-precision argument before confirmation outcomes, with evidence of what prediction improvement changes scientifically. The old 5% development filter is not a validated useful margin. Neither technical GxE errors nor 96 compound rows estimate independent-culture variance. The nonquery precision pilot estimates culture/reference covariance, but that alone does not estimate the eventual candidate's paired-loss SD. Reserve disjoint power-design blocks from nomination and confirmation before any access, freeze the candidate/comparator before releasing those outcomes, and estimate SD of their paired block losses there. If pilot outcomes have already been used to choose the candidate, obtain genuinely separate power-design observations rather than relabeling them. Review variance uncertainty, nonnormality, missingness and cost before choosing n. These additional blocks and their assay costs are not included in the illustrative confirmation-only totals. No pilot or power-design cultures are counted as confirmation cultures.

The two context claims are co-primary. Use one-sided tests of `E[D_cj] <= delta` with alpha .0125 per context, giving a Bonferroni family false-positive bound .025. Both adjusted lower bounds must exceed delta; otherwise no overall success. Under independent identically normal block loss differences, power is `P(T_(n-1,ncp=sqrt(n)*k) > t_(1-alpha,n-1))`, where `k=(E[D]-delta)/SD(D)`. This explicit planning model is documented by [paired-observation inference](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm) and the [noncentral t distribution](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nct.html). It is not a validated biological model.

Obtain a pilot-based uncertainty range for SD, a reviewed margin/expected excess, acceptable error/power, actual attrition and a quote. Validate the chosen culture/block interval procedure's null/type-I and coverage under that design before registering n. Small-n cluster bootstrap or cell resampling is not assumed calibrated. If assumptions fail and no defensible affordable alternative exists, stop rather than select a favorable analysis.

Report prespecified adjusted lower bounds and culture-level paired differences, support, failures and reference-role sensitivity. Secondary MAE, retrieval, gene correlations, contrast/program endpoints and per-pair effects remain descriptive unless a separate multiplicity family and biological estimand are registered. Alignment/identity shuffles, no-change/additivity and locked-reference fallback check calibration, information attribution and operational behavior; they do not establish mechanism. No functional utility claim is made from transcriptomic accuracy alone.

## Resources, approvals and final decisions

Required people are an assay/culture PI, trained culture/perturbation operator, single-cell or compatible transcriptomics facility, data custodian, biostatistician and institutional research/rights support. Required materials include actual authenticated/mycoplasma-tested stocks, interventions/reagents, matched vehicles, culture/reference supplies, sample barcoding, library preparation/sequencing, controls and QC. Personnel time, sequencing depth, repeat/failure costs, storage, currency and sample shipping need actual quotes; none is supplied here. Cell lines, genetic reagents or human material may require biosafety/MTA/data/consent or ethics review as determined by the host institution. No approval or exemption is inferred.

Before any run obtain a genuine supplied owner operation acceptance, institution/laboratory agreement, source research/export rights, reviewed SOP/randomization/margin/power/QC, nominated procedure and complete measured resource envelope. Before any contact obtain explicit send authorization; this draft is unsent. The frozen 14-gate transfer checker remains 0/14 and is not modified to accept this narrower accuracy design. A claim-specific independent-culture registration is required; unseen-context transfer would additionally need the original crossed-context/bridge requirements.

Success requires nomination, complete supported primary population, exact freeze/replay integrity, both useful adjusted lower bounds, required attribution/negative-control support and no method fallback. Failure means adequate integrity/precision with an adjusted upper bound excluding a useful improvement in a required context; it rejects that procedure/population, not all biological prediction. Intervals crossing the useful threshold, excess missingness or inadequate power are inconclusive. Source/rights/integrity failure stops unblinding; inadequate affordable measurement precision stops commissioning. Only a predeclared, costed pilot extension is allowed, with no confirmation outcome-driven model or sample-size rescue.
