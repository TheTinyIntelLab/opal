The root adopted G's concrete repairs in [experiment_contract.md](experiment_contract.md): relative singular tolerance 1e-8, condition number at most 1e4, leave-one-bridge stability, source-only unit-RMS mode scaling, per-gene loss, and explicit source-context selection limits. It also adopted D/E's primary response MSE and rejected using centered residual error as an independent interaction claim. F's intermediate three-scalar suggestion is preserved as superseded, rather than becoming an implementation instruction.

Meaningful disagreement remains. B initially favored broad crossed single-response representation work because it can cheaply test context information; A/C/F/E favor directly observing target pair information because single-transfer success does not establish composition. G favors comparing bridge assays with reference-precision investment when a collaborator can measure equal-cost designs. No public simulation currently settles that budget tradeoff. The final plan chooses sparse bridge transfer first because it directly tests the additional composition information missing from prior failed context studies, while retaining the single-response task as a bounded fallback.

Agreement among agents is not scientific evidence. Their critiques reduced confounding and made the experiment reviewable; the promotion decision still requires measured outcomes and the independent evidence gates in the plan.


Final root response to G: the contract now fixes equal bridge weights, per-gene averaged loss, source-only unit-RMS modes with a numerical floor, the finite cross-fitted nuisance menu, and the exact normalized inverse retrieval-rank endpoint and paired pass rule. The implementation handoff also charges the union of bridge identities across folds and each stratum/culture measurement. These repairs address the final review conditions; they do not remove G's unresolved biological and equal-cost allocation criticisms.
