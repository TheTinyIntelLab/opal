## One next objective

Obtain independent culture/reference precision on a small completely crossed nonquery panel. Determine whether adjusted pair/context residual contrasts repeat at a biologically useful scale after accounting for shared reference noise. [The proposed protocol](docs/frontier/measurement_precision_next.md) specifies hypotheses, units, source requirements, culture/block splits, controls, analysis, resources and decisions. Its six-intervention/fifteen-pair topology and administrative culture count are drafts, not powered or commissioned measurements. Actual reagents, partner, margin, power, rights and quotes remain missing.

Another architecture on exposed outcomes would reuse failed/mixed controls without creating independent evidence. A large single-response atlas cannot identify pair-residual biological precision by itself. Repeating source-ineligible preparation cannot recover missing assignments. A better-qualified dataset is worth acquiring only if it supplies the exact independent units and reference lineage needed here within a feasible accepted envelope.

Continue only after literal compatibility/rights, independent cultures/references and reviewed biological utility are established. Promote to a separate finite predictive registration only if calibrated culture-level evidence supports useful adjusted contrast with adequate reference precision/coverage. Adequate precision plus an upper bound excluding useful signal retires this formulation for the tested population. Reference-dominated error permits only a predeclared costed precision redesign. Inconclusive or provenance-limited results do not justify a rescue model sweep.
