# F: systems, compute and training strategy

Status: independent initial investigation, 11 October 2026. This report inspected the extracted manuscript, actual implementation, frozen configuration, release manifest, saved resource ledger and new efficiency report. Numerical results below are artifact evidence unless marked as a present-host measurement or proposed budget. It did not rerun scientific training or load protected historical evaluation responses.

## Decision

Build a CPU-first, sparse target-context calibration experiment with acquired bridge pairs, a frozen source-derived output basis and a tiny target-context operator. Treat new crossed labels as the intervention; do not simultaneously introduce a pretrained backbone, a new expression endpoint and a learned state encoder. Current systems already support safe checkpoints and exact replay, whereas neither existing biological results nor the available GPU justify foundation-model scaling. A positive experiment would justify more crossed pair/context data before a larger network.

The hypothesis is that a small number of target-context pair measurements identifies a reusable change in the source residual map that generalizes to globally unseen pair identities. Its strongest competing explanation is a shared offset or affine recalibration of expression responses. The operator must beat those alternatives with exactly the same bridge labels; improvement over an unadapted source model is insufficient.

## Verified engineering baseline

`src/models/kernel.py` implements closed-form symmetric kernels with an unpenalized residual intercept, centered kernel solve and source-reference scaling. Training cost is approximately O(n^3+n^2 G); inference is O(qnG) after kernel construction, and coefficients plus reference profiles count as deployed storage. The implementation also has an exact residual-Gram scoring route, avoiding reconstruction of every full-gene candidate during selection. This is useful when scaling labels, but the cubic solve eventually becomes the bottleneck rather than neural parameter count.

`src/series_bilinear.py` exports hash-bound NPZ/JSON checkpoints with optional content-addressed array stores. `src/series.py` rejects changed query hashes, contract hashes and deployment checkpoints in the retrospective evaluator. `src/information.py` supplies safe information-head loading, explicit unsupported-rank fallback, control-only projections and separate global-pair/partner masks. Reuse those safeguards, but create new bridge/context splits: the existing `split_masks` routine alone does not implement crossed global-pair plus held-context exclusion.

`configs/experiments/opal_information_v1.json` freezes a 24-core-hour, one-thread, one-worker study and a finite grid. `results/opal_information_v1/resource_ledger.json` records 2,924,808,209 retained bytes under a 3,000,000,000-byte inherited ceiling, leaving **75,191,791 bytes**, not several gigabytes of usable study headroom. Its existing 3,142,132,144-byte raw H5AD is explicitly outside that artifact classification, so the artifact cap is not a complete disk-use claim. D and E remain historical read-only storage under the inherited reserve policy.

Present host interrogation gives 34,115,923,968 physical RAM bytes and an NVIDIA GeForce RTX 4060 with 8,188 MiB reported memory. ## Scientific implications for resource allocation

The manuscript's original neural results beat additivity but do not reliably beat selected simple references. Later cross-coordinate heads improve only 0.077882% and 0.083848% on responsive primary panels; variance loses to capacity-matched mean controls, with unsupported TNF-negative partner selection. These are grounds to stop increasing capacity under those information contracts, not grounds to reject all cell heterogeneity or context information. The common-population Wessels extra-pair experiment is evidence that supervision may be more valuable than tested single coverage in that exposed development population, not an extrapolatable scaling law.

Full-gene PertAdapt float32 feasibility previously exhausted this GPU and its distributed launcher needs unavailable Windows NCCL. A successful 256-token synthetic probe does not reverse that conclusion. The manuscript's suggested 48-GB Linux profiling target is a proposed profiling allowance, not a measured minimum requirement. No costly native backbone run belongs on the critical path until added information beats the strongest simple control.

## Minimum implementation and controlled experiments

Use a separate identifier such as `frontier_bridge_v1`, with new manifests, frozen source roles, bridge roles and evaluator roles. Supply matched control/single effects in both contexts, acquired target-context bridge-pair effects, source pair effects, exact canonical pair IDs, stratum/culture lineage and gene/normalization hashes. Exclude every test pair identity from every source and target-context pair-response access before building any PCA, output basis, memory, hyperparameter score or bridge acquisition list. This distinguishes new-combination context calibration from response transfer for an already measured combination.

Freeze the existing source-selected Base/kernel procedure. Fit its residual output basis on source training labels only. Start with a rank-two-plus-intercept target-context linear operator in source coefficient coordinates; choose its single regularization constant only within development bridge labels. A rank-two operator with an unrestricted two-coordinate intercept contains six fitted coefficient-space values, but the source basis, Base state and references remain part of the complete system. Require at least enough distinct bridge pairs to identify the design and a nested validation split; a nominal bridge budget below support must produce unavailable results rather than a favorable subset.

At identical bridge budgets compare: zero bridge/no adaptation, bridge mean residual, scalar affine-additivity correction, global response calibration, target-incidence correction, source kernel with equal-label bridge refit, and the rank-two operator. Retain no-change and additivity. For complexity attribution compare a matched linear map with the same number of fitted values on additive-response coordinates; shuffle pair/bridge correspondence within legitimate context/stratum blocks. Source output rank must not be selected on evaluator labels. Include a synthetic positive-control operator and a shared-offset negative generator before scientific scoring.

**Data control:** run nested identity-only bridge prefixes, proposed budgets 0/8/16/32 when support exists, three fixed order seeds, on one unchanged query population. Explicitly enumerate whether a bridge pair is repeated across contexts and count both unique pair identities and independently assayed pair/context/culture conditions. All tuning and calibration labels count toward budget. Reduce the grid if any population cannot support it; record unavailability rather than acquiring new information after viewing scores.

**Capacity control:** initially compare intercept-only, fixed rank-two operator and an equally regularized six-value additive-coordinate head at fixed labels. A later rank-four operator is a new finite development experiment only if rank-two passes scientific attribution and its held development errors suggest recoverable output directions. Do not use a very broad kernel menu and a tiny neural menu to infer architectural superiority, and do not equalize only parameter count while unequal label/tuning access remains.

**Objective control:** keep the registered condition-mean endpoint. A distributional objective has different observations, noise and evaluation; it is a separate branch contingent on independently repeatable distributions. A new gene weighting must be qualified before it becomes a selection endpoint, because retrospective DEG panels can turn outcome information into apparent progress.

## Resource receipt contract for the coding agent

Write one launch receipt per process before training and atomically finalize it on success, failure or exception. Record run ID, parent PID, command/config/code hashes, environment/container hash, hardware, thread counts, precision, wall timestamps, CPU user/system totals and exit reason. Include failed attempts and preparation, hyperparameter search, stopping, replays and compilation as distinct cost stages. Capture child CPU at exit where possible; if any component is missed, label the aggregate a lower bound.

Measure OS peak process and sampled process-tree RSS separately; sampled peaks can miss spikes. For GPUs record allocated and reserved peaks, maximum observed device use and synchronized train-stage wall time. Use a profiler for actual device/kernel duration when available; retain null when unavailable. Report cold load, warmed single-pair latency, batch throughput and peak inference memory with the batch size and reference-loading scope.

Separate learnable scalar parameters, fitted non-gradient coefficients, nontrainable buffers, complete checkpoint bytes, shared reference/array-store bytes, pretrained assets, raw data, preparation intermediates, wheels/environments and total retained filesystem bytes. Count shared physical assets once in a total, while declaring dependency bytes for each deployed model. Hash final predictions, checkpoint metadata and array dependencies. Save selected final and OOF checkpoints plus compact losses; do not duplicate every candidate's full references. No historical deletion or evaluator re-selection is needed.

## Go/no-go and disagreement

Do not build a new architecture because the current family is small. Build one only if equal-information simple models plateau while a controlled representation or capacity increment yields reproducible added capability, with independent confirmation planned. For bridge calibration, require improvement over every equal-bridge simple comparator, global-pair exclusion, nontrivial pair-specific gain beyond the offset control and support in more than one qualified context transition before compute scaling. The scientific gate should be predeclared from assay utility/power; an administrative percentage can triage development but cannot certify biological utility.

My concern with the leading bridge proposal is that target-context labels may improve only the intercept or dose/guide calibration, and its tiny output rank may erase the very pair-specific structure it claims to transfer. If shared offset/affine/global calibration wins, retain that simple model and classify the outcome as calibration. Do not promote a transformer to rescue the negative result. If all valid bridge models fail but fresh replicated labels show reliable heterogeneous interactions, the next investment is structured crossed supervision; if no repeatable useful target exists, change the task to a validated phenotype/ranking endpoint before additional compute.

## Actual cross-examination and revised recommendation

I read B's data recommendation and C's architecture recommendation after completing the independent report. B's strongest addition is the distinction between broad public crossed single-response information and genuinely crossed pair information. Its proposed Tahoe precursor could test context representations beyond the failed three-line regime, but success would not identify combination effects. It should not become an extra prerequisite in the same first experiment: source qualification can proceed in parallel, while the bridge study isolates acquisition of actual target pair information. The full Tahoe card's approximately 429-GB resource is not a workstation download plan; a bounded subset still needs an exact metadata-only byte inventory, because the inherited artifact headroom is only 75.2 MB. Public data accessibility and storage approval are different facts.

C correctly identifies that four or eight bridges cannot justify an unrestricted target operator, and that a shared correction may explain all benefits. I materially revise my initial six-value operator suggestion: freeze two source-learned adaptation directions and fit only their **two scalar target coefficients plus one scalar intercept coefficient along a source-fixed intercept direction**. This is three acquired-label degrees of freedom; a full G-dimensional target mean offset remains a strong competing calibration reference and its full fitted-value count must be disclosed. Match the three-value operator with a three-value additive/global calibration head, retain the mean-vector offset and target-only kernel as stronger practical baselines, and require nested support rather than claiming that eight nominal bridges suffice everywhere. A six-value 2x2 map is a separately gated successor, not the default prototype.

C's proposed independent-culture repeatability requirement is essential before biological or frontier promotion. I disagree that absent independent cultures must block every 30-day computational experiment: an exposed public two-state panel can legitimately falsify the numerical bridge hypothesis under its deposited measurement contract, provided its output is explicitly retrospective sample-context development and never called biological state transfer. A qualified new replicated source is still required for advancement. This distinction preserves a decisive inexpensive first study without pretending technical labels are cultures.

Remaining disagreement: B prioritizes broad single-response representation transfer, C initially prioritizes zero-bridge context contrast and now supports sparse bridge calibration, while I prioritize the target pair information intervention because the current state/representation failures and small-GPU limitations make it the smallest test capable of changing the composition research direction. A valid bridge failure does not refute B's single-response task, and single-response success does not rescue an unfavorable bridge result. The root should choose one dominant experiment and retain the other as the predeclared alternative rather than mixing them.

## Final contract reconciliation

The root's final `docs/frontier/experiment_contract.md` supersedes my provisional budgets and scalar-intercept revision above. The executable first study acquires **exactly four bridge pair identities**, with zero bridges as its sole diagnostic; it has no 0/8/16/32 acquisition grid and no target-context validation search. Source-only development chooses the source configuration, while target penalty is fixed at one. This substantially reduces retained predictions and training calls, making the 24-core-hour / 60,000,000-byte allowance conservative pending the first measured pilot.

The adopted predictor fits a **gene-vector shared bridge intercept plus two scalar mode coefficients**, so target fitted freedom is **G+2 values**, not three scalar values. Every applicable calibration control receives the same G-dimensional bridge intercept, and the equal-capacity adapter receives the same two scalar coefficients. The gene-vector offset costs 8G raw bytes in float64; source modes, source maps, Base/kernel coefficients, scalers, bridge means and references remain additional complete-system assets. Four pairs supply four independent condition-level rows; G genes cannot be counted as G independent biological observations. Source modes and target centered design require rank-two qualification and explicit singular values/condition-number reporting; ill-conditioned or unsupported designs fall back on the frozen selector and do not constitute successful adaptation. Source-only RMS mode normalization and any conditioning cutoff must be frozen in that root contract before scoring and persisted in checkpoints.

I accept this G+2 formulation because it puts the shared-offset explanation directly into every matched arm, making the two composition coefficients the precise incremental claim. The earlier scalar-intercept recommendation would have artificially weakened shared calibration and is withdrawn. The earlier bridge-budget grid remains an initial position only and must not be implemented in this first study. Reconcile all resource receipts against the root's exact fixed experiment, preserve the independent initial reasoning and cross-reviews above, and use the root contract as the coding authority.
