## Hypothesis and exact first procedure

For a new pair identity whose outcomes are globally excluded, differences between its measured single responses in two observed contexts predict the difference in pair residual response beyond shared calibration, main effects and equally informed kernels. The 18-feature term earns nomination only if it improves full response error and qualified discrimination beyond the eight-feature contrast reference.

For each literal intervention i, aggregate matched technical strata equally within context to obtain allowed single effects m_ic. Pair outcome effects Delta_pc retain their original stratum support and are aggregated equally for the primary fixed-contrast diagnostic. Record all stratum-level secondary results separately. This is a new declared aggregate endpoint, not v1's failed scoring population.

Define:
```text
r_pc = Delta_pc - m_Ac - m_Bc
t_p = r_p1 - r_p0
z_ic = P^T m_ic
d_i = z_i1-z_i0
zbar_i = (z_i1+z_i0)/2
phi8 = [d_A+d_B, abs(d_A-d_B)]
phi18 = [phi8, vech(sym(zbar_A d_B^T + zbar_B d_A^T))]
```
P has four columns. The symmetric block has ten entries; sqrt(2) scales off-diagonal coordinates. Every transform is training-fold-only apart from declared measured query references. Query pair responses are never representation inputs.

Fit a pooled symmetric residual kernel k to training-pair mean residuals across contexts, then a shared training contrast h and output basis B. Cross-fit nuisance estimates before residual head/basis construction. Normalize B so B^T B/G = I with two output columns, meaning unit gene-RMS rather than a G-dependent ridge strength. Center/standardize feature columns with training-pair moments and persist floors. Fit:
```text
min_W (1/(nG)) sum_p ||t_p-h-BW phi18(p)||^2 + lambda ||W||_F^2
t_hat = h + B W phi18
Delta_hat_0 = m_A0+m_B0+k(p)-t_hat/2
Delta_hat_1 = m_A1+m_B1+k(p)+t_hat/2
```
The final pooled kernel/nuisance refits use training identities only. Full-response inner validation selects lambda; low contrast-training loss is not the selection criterion. Head coefficients number 36; the contrast-only reference has 16. Count h, B, P, scalers, kernel banks and every permitted reference in inference assets.

Both contexts participate in training. No target calibration pair is acquired for this diagnostic. It does not run two source-to-target directions; it predicts both observed contexts on globally withheld pairs. Changing to a held-context task requires the future registration.
