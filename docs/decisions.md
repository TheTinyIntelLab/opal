# Opal research decisions

## 5 October 2026: next-cycle implementation

The historical benchmark and later exploratory development records retain separate identities. New audit and attribution outputs go under `results/next/`; the next command does not execute the historical evaluators or overwrite their reports. A retrospective archive cannot create a prospective historical freeze.

The next model reference is the residual kernel. Kernel attribution compares independently retuned components, fixed-selection branch removal, a shuffled feature mapping, and matched near/random training-pair removal. A reproducible contribution from another representation would justify changing that reference.

The first contextual input contract requires measured singles and controls in every declared query context. Missing singles, repeated targets, cross-modality pooling, and cross-assay pooling are unsupported. Separate data and evaluation would justify additional contracts.

Context transfer needs crossed biological data. The implementation supports this task, but synthetic execution and pooling current incompatible sources cannot establish that capability. Accepted overlap, provenance, exposure, and replication evidence would permit biological evaluation.

Calibration outcomes cannot select the model. Grouped error radii are empirical diagnostics, and shared targets/references plus context shift prevent a formal coverage claim here. Independently assessed reliability would justify an abstention capability.

The master-plan file remains local through `.git/info/exclude`, following the user's instruction. It is not part of the release or reproducibility archive.

The measured-single sum kernel is now included in the contextual candidate set. On the existing development-only Wessels random folds it reaches MSE 0.005031 versus 0.005192 for pair-product geometry; partner folds remain much worse at 0.010053. These results do not support treating pair multiplication as the source of the improvement.

The user authorized the local RTX 4060 and autonomous public-data acquisition. CUDA 12.6 PyTorch runs in a separate `.venv-gpu`; the original CPU environment is preserved. EmeraldBay provides a separate chemical transfer pilot with exact compound/dose matching. Cell-line membership, feature selection from vehicle controls, and source coverage select the pilot without using combination expression scores. It does not extend the genetic intervention claim or provide independent confirmation.

The independent D-SPIN procedure test fails the material-skill gate, and the source-calibrated radius has only 34.3% held-lineage coverage. Keep context-transfer and calibrated-abstention claims closed. A positive sealed test with independent biological replication would change this decision; retuning on D-SPIN's exposed outcomes would not.

Native CPA outperforms the kernel on the chemical pilot under the aggregate-input adaptation. Keep both checkpoints and report CPA as a stronger exploratory candidate, with its original BSD notice and exact no-label restore. A canonical, information-aligned cell-level confirmation is needed before a broader ranking. Native GEARS development results now exist under an explicitly reference-graph aggregate adaptation; these are not interchangeable with canonical GEARS scores.

The separate estimated-single route is now implemented and tested. Main effects, residuals and their error cross term must remain visible because the low pilot total error depends on cancellation. A 0.5% source-validation improvement over target averaging does not meet the 5% main-effect complexity gate, so do not add a learned encoder merely to complete an architecture diagram.

The default native PertAdapt adapter runs out of memory on the 8 GB GPU; the supplied distributed launcher also lacks NCCL on Windows. Preserve the failed probe. A compatible environment, a full measured gene alignment and a declared pretraining/graph access contract must precede a scored native run.

Clean-install verification found that the legacy export recomputed its reference bandwidth at load time. BLAS thread-count changes altered numerical distances and the missing-single predictions. State version 3 now persists the fitted gene scales and reference bandwidth. New observed and estimated exports agree across the CPU source and installed GPU environment without requiring the training thread count. Legacy experiment records are preserved, and the portable-checkpoint migration does not reopen evaluator outcomes.
