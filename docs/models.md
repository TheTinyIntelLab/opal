# Model guide

Use [prediction and model availability](usage.md) for the v1 API. GitHub contains no biological checkpoints. Download the separate model repositories from [Opal Growth](https://huggingface.co/TheTinyIntelLab/opal-growth), [Opal Norman](https://huggingface.co/TheTinyIntelLab/opal-norman) and [Opal EmeraldBay](https://huggingface.co/TheTinyIntelLab/opal-emeraldbay). The older guide is preserved in [the historical documentation archive](archive/README.md).

The six-task growth delivery is an assay-local research model with a failed all-task promotion criterion. Norman and EmeraldBay kernels are historical expression references. None is a general biological simulator, a validated causal interaction model or a frontier-performance claim.
