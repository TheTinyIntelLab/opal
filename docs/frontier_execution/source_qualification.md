COLO1 does not qualify for response access. The metadata investigation established a pinned documentation route, an exact Figshare file identity and response-free ENA keys, but it did not establish the mappings and endpoint prerequisites needed for a fair biological task. This decision authorizes no response headers, values, archive member bodies or outcome-derived eligibility filters.

| Prerequisite | Decision and evidence |
|---|---|
