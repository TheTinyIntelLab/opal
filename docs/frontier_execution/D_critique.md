## Model parity and finite capacity

1. **Resolve the feature mismatch with C.** C proposes a structured world driven by independent two-dimensional gene features and a nuisance world with supplied guide/arm/batch covariates. B's kernel consumes only identities and singles, and its neural network consumes identities through embeddings. Merely handing every fitter a feature array does not establish useful parity when no candidate uses it. Either add a prospectively specified feature-matched additive reference and feature-consuming kernel/composition variants within the existing configuration cap, or label the world an unavailable-input control and narrow its purpose. Do not add oracle latent factors after a failure. Construct covariates also need a nuisance-aware reference and actual construct-level predictions if nuisance recovery is claimed.

2. **Keep the kernel distinction explicit.** B defines a positive semidefinite base kernel combining identity and single similarity, then symmetrizes its tensor product. Identity-by-single interactions can represent partner curves that B3's smooth singles map plus additive gene incidence cannot. That is a genuine symmetric pair kernel, while a kernel using singles alone would remain a flexible compositional singles model. Both kernel and B3 should receive the same TRAIN-only standardization and supported queries. Freeze the 64-landmark hash salt, eigenvalue threshold as absolute or relative, treatment of small negative roundoff eigenvalues, ridge/intercept convention and deterministic eigenbasis/replay contract. Repeated eigenvalues and eigenvector signs do not establish bitwise portable reconstruction; save the fitted basis and test prediction replay on the pinned stack.

3. **Finish the completion equation before calling it retained.** B's signed four-positive/four-negative, 500-step Adam comparator is an explicit proposal for a new one-context implementation, not demonstrated reuse of the historical rank-eight recipe. C confirms the existing completion fitter requires two contexts. Bind the exact residual objective, loss normalization, factor penalty, initialization, optimizer epsilon/betas, update order, parameter dtype and unsupported-gene behavior. Do not feed initiation two into fitting or duplicate initiation one to satisfy a historical signature. Name the new contract accurately and preserve historical checkpoint behavior.

4. **Complete the neural numerical specification.** B supplies embedding dimensions, ReLU layers, L2 settings, steps and learning rate, which prevents a width/epoch search. Clarify that the stated shared 4-to-8-to-4 transform has two linear layers, its activation placement, output bias, Xavier gain, Adam defaults and whether the mean-square penalty averages over all scalar parameters or separately over parameter tensors. Those choices change regularization by parameter count. Freeze batch order and optimizer state if replay includes training; checkpoint replay alone should load saved parameters without optimization. This model is NAIAD-like and must not be described as a native reproduction.

5. **Make the flexible reference reproducible in degenerate cells.** B's 64 radial-basis map with and without gene incidence is a useful stronger-single control. Specify distance-median computation without response access, repeated/small center sets, zero-range single effects and rank deficiency. Freeze intercept and basis scaling consistently. C recommends refusal for small/degenerate historical cases, whereas B proposes min(64,n) and a bandwidth floor. A new method may use B's policy, but it must be named and tested as a new bounded implementation rather than silently modifying the historical flexible-single contract.
