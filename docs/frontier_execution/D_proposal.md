## Proposed comparison

Use a shared, TRAIN-fitted reference selected on the charged VALIDATION subset. Separate fixed/null, calibrated-single, gene-incidence and flexible-single references from residual completion, explicit symmetric pair kernel and finite regularized neural composition. The flexible-single map must remain a serious competitor: train-only knots or centers, symmetric coordinates, bounded basis, and its own declared penalties. A smooth function of sum, absolute difference and product of singles remains a flexible-single method even when called a kernel.

For a genuine symmetric product kernel, define a permitted per-gene feature map phi and k_sym({i,j},{u,v}) = [k(i,u)k(j,v) + k(i,v)k(j,u)]/2 with a positive semidefinite base k. An explicit symmetric tensor map implements the same contract. Singles-only phi makes this a compositional singles baseline; identity or independent metadata features change its hypothesis class and must be supplied to matched additive references. Declare whether signed interactions are expressible, feature dimension, normalization, ridge grid and reference residualization. Do not silently use all-pair target statistics to build the map.

For neural composition, freeze one small shared encoder and an order-invariant combiner, such as elementwise product plus sum, a bounded hidden width and output head. Declare activation, optimizer, learning rate, maximum steps, batch rule, regularization values, initialization seed and deterministic tie rule numerically before evaluation. At most four substantive configurations per family prevents an uncharged search through architectures and training durations. A new composition network is not a reproduced NAIAD model without pinned native implementation and matched settings. Free gene embeddings imply a training-supported-gene task and require an explicit unsupported-gene response.

Random-pair holdout estimates unseen edges among supported genes. It supplies no cold-gene evidence because gene incidence and embeddings can use outcomes incident to each TEST endpoint during training. A separate cold-gene registration must exclude every incident TRAIN and VALIDATION outcome and define what information supports a new gene. No cold-gene run is added to this finite matrix by implication.

Graph methods remain conditional. Qualify a specific graph's revision, rights, provenance, outcome overlap and deployment availability before admitting it. A synthetic graph generated from the same latent factors as truth is privileged information unless that dependence is the declared world. Provide feature-matched references and graph permutation/ablation controls. Missing graph assets do not justify invented biological features or block the non-graph tournament.
