# Bounded whole-metadata-object identity contract, v2

The v1 acquisition returned 200/application-octet-stream without Content-Length and closed unread at its declared header gate. Preserve that failed receipt unchanged. Absence of that transport header is not evidence of a missing member. This version introduces a different metadata-transport contract, never a retrospective v1 pass or relaxed scientific criterion.

For this one complete, documented row-annotation object, byte identity is decidable from the pre-wave Git blob SHA1 and the exact size/CRC already supplied by the licensed primary container catalog. A Content-Length declaration cannot establish those identities. Therefore permit an absent Content-Length while retaining rejection of any contradictory length, non-200/nonbinary/encoded envelope, redirect, wrong byte count, wrong Git blob or wrong CRC. This changes only the transport-header requirement. It does not permit another source object, larger payload, deserialization, response ingestion or fitting.

Authorize exactly one separately registered GET of the same explicit IDS member link, no retries or redirects. This is an intentional versioned transport experiment, not an automatic retry of v1. Read incrementally at most 277,296 bytes, then close; accepted object length must be exactly 277,295. Require unchanged Git blob `b88d727fdc3f34109d07a94cfae44aad99405990` and CRC32 508845907, and record independent SHA256. Preserve any mismatched opaque bytes in quarantine with identity failure. No metadata values, table/header deserialization, other member, whole archive, numerical response object or upstream script may be opened.

Freeze this registration, v1 code/failure receipt/freeze and original raw technical catalog before new code. Bind v2 coordinator and fixtures before execution. Challenge absent versus contradictory lengths, exact byte cap, same-size corruption, wrong CRC and wrong Git identity. Use a known synthetic Git blob identity independently of the candidate code. Limits remain 30 seconds transport, 60 seconds external wall, 512 MiB sampled memory and 1 GiB reserve. One metadata GET; no parser dependency or RDS interpretation yet. Later content/schema audit needs its own registration after byte identity passes. Root-only attribution; zero source qualification for responses, reserved SPIDR/Shen access, fits or scores. All scientific tolerances and historical stops remain unchanged.
