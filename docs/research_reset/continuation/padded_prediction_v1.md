# Fixed-shape BLAS padding experiment registration, v1

Root inspected the existing frozen candidate definition before this proposal. Wave Five tested legacy/matmul/einsum/ascending contractions and varying caller batches, but its variants do not pad contraction operands to a constant row dimension. This is a distinct numerical hypothesis, not another biological fit or an inference from new candidate results. The COLO1 range experiment independently stopped at its ETag gate with zero body bytes; preserve that negative result.

H1: padding the whitening left operand to a constant number of rows can avoid shape-dependent BLAS kernels while retaining closer legacy compatibility than changing reduction order. H2: padding the final projection as well may improve self-invariance, but row-slot/tail kernels can still defeat compatibility or reordering. H3: irrelevant filler values should not affect retained rows, while the position of retained rows may expose backend-specific arithmetic. Null: no padding candidate meets both unchanged gates. No success is required or presumed.

Freeze four candidates: row tiles 128 or 2048 crossed with whitening-only or whitening-and-projection padding. Use native float64 C-contiguous padded operands, zero fillers, leading valid rows and the unchanged whitening matrix/coefficient, centers/scales, feature construction and `(additive + offset) + dot` grouping. Discard only filler outputs. The whitening-only candidate leaves the final original projection unpadded. The joint candidate pads already standardized features to the same tile size before its final contraction. No kernel recalibration, scale change, fitted coefficient update, new labels, lookup of outcome values or checkpoint mutation. A candidate may internally divide a caller chunk into fixed tiles; every final tile is padded too.

Run each candidate in two fresh one-thread processes, plus two fresh two-thread processes for joint-2048: ten finite jobs. Execute sequentially to isolate resources. In every process reconstruct both historical failures from their immutable saved states, without fitting/test scoring. Reference is the original selected Q2b checkpoint predicting the original ordered 15,779 validation queries in its internal 2048 procedure; this is a reconstructed vector, not a newly discovered archived reference. Allowed bank fields remain genes/pairs/singles and the frozen split assignment. Fit/prepare/solve/lstsq calls must trap. Require exact historical failure reproduction and unchanged absolute 1e-12/relative zero comparisons. No alternative threshold may pass a failed reference.

For every candidate record full-validation compatibility, maximum absolute/relative errors, affected row positions, hashes, finite values and first divergent stage. Trace 129 evenly spaced query positions plus the final four positions against their original reference blocks. Caller controls cover full validation with chunks 63, 257, 2047, 2049 and complete length, reverse order, seed-510523 permutation, reversed pair orientation, Fortran query layout and a non-contiguous query view. Bounded singleton and irregular (1,3,17,2,65) controls use those registered trace anchors, compared to the corresponding full-candidate outputs, not a changed reference. Also test anchor rows placed at trailing padded slots and repeat-first-row fillers, plus 65 repeats each of the first/middle/final query, checking order and occurrence preservation. Every scope and discrepancy remains visible; singleton control is not claimed for all validation rows.

Bind the original external state hashes and current experiment/helper/model code before execution. Recheck before and after each process. Limits: 300 seconds external wall and 2 GiB sampled process memory per job, 1800 seconds cumulative controller wall, 1 GiB disk reserve, at most ten jobs. Record Python/NumPy/BLAS/thread metadata and actual wall/CPU/peak. No plotting, source requests, reserved SPIDR/Shen outcomes/headers, new fits, biological scores or model promotion. Root-only execution is not independent A/C review; the existing worker cap and provider failures remain disclosed. The two-failure scientific stop remains in force. Compare all registered candidates before deciding any implementation; a positive numerical result would still need broader counterexamples and independent review before a new scientific registration.
