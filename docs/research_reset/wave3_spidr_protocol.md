# Wave three SPIDR metadata qualification v1

This registers a metadata-only successor, not a normalized-count endpoint or
permission to open responses. Start from main 505af4d9dd6a77f73b0e8952c9f4ed8cc12725a6.
The timestamped JSON registration binds this protocol, executable, tests, existing
projector, plan, source receipts and verified local Table 2 ZIP before execution.
No SPIDR or SCHEMATIC response table or header may be opened or downloaded.

## Scope and selection

Perfect/perfect is the primary metadata role, following the prospective root-plan
decision; mixed and both-mismatched are secondary. Preserve historical protocols.
The existing raw-count adapter still hardcodes both-mismatched and rejects
normalized input. The prior all-stratum design receipt explicitly records
`primary_changed=false`. The wave-two source registration is a readiness audit,
not an implemented normalized endpoint. This successor does not repair that
endpoint by guessing units or invocation.

Use only the existing hash-verified library at the path bound in the runner.
Retain the historical six-column identity allowlist in each arm. Historical
activity annotations are discarded without numerical conversion or use. Do not
load original response banks, guide activity values, GEMINI or GI scores.
Validate archive identity, member size/schema, CRC through complete streaming,
consistent guide identities, explicit mismatch/transcript metadata and duplicate
ordered exact reagents. A failed check stops the branch and preserves its failure.

## Designed eligibility and accounting

Count unique ordered constructs, control/control, target/control and same-gene
constructs separately. Match a target single design by exact sequence, transcript,
gene, mismatch annotation and vector arm. Controls have explicit reviewed
`negative_control` roles from Table 2 plus official methods, with blank transcript
and mismatch meaning not applicable only for these controls. Report NT-partner
counts for every target arm, including zero. First require two ordered constructs
within each canonical pair/stratum, then two with at least one exact NT partner
for each constituent arm. Report cumulative pair counts and nonoverlapping
missing-arm construct exclusions at each stage. One NT partner establishes a
design opportunity, not measured single availability or sufficiency after QC.

Assign all variants, orientations and strata of a canonical unordered gene pair
by SHA256 of UTF-8 `opal-reset-v2|PRJNA988447|geneA|geneB`, first eight hex digits
modulo ten: 0-5 train, 6-7 validation, 8-9 test. Save primary design assignments,
hash, partition sizes and lookup support. These are prospective design partitions;
observed T0 coverage, culture/time linkage, matched measured singles, QC and test
eligibility remain unknown. Do not call the design test count an eligible test set.

## Safe official review

Make at most one request each to the exact article XML, official Supplementary
File 1 DOCX and ENA metadata-only PRJNA988447 report listed in the code/registration.
Use GET only, 30-second request timeout, 8 MiB body limit per request, 24 MiB total.
Redirects must match the same exact allowlist. No response URLs, HEAD/range calls,
schema probing, linked assets, FASTQ or arbitrary crawl are permitted. Record URL,
length, SHA256 and structural facts; do not store article bodies or source files.
For the supplement, inspect only document XML code/function paragraphs, never
images. Record signature/replicate-map facts and code-excerpt hash. A definition
is not an actual invocation or sample map. If official evidence does not supply
compatibility, retain the blocker rather than infer a normalized endpoint.

## Metrics, gates and resources

There are no fits, predictions, biological metrics, uncertainty estimates or
outcome-dependent choices. Exact metadata counts/histograms and tests are the
acceptance criteria. The historical future gate remains paired identical-pair,
identical-information MSE, at least 5% improvement, upper conditional gene
loss-difference bound below zero, no replicate loss, all-reference robustness
veto and all three shuffled controls. At least 50 observed eligible primary test
pairs and ten genes remain required. The 2,000 endpoint-multiplicity gene draws
with seed 20261022 are conditional sensitivity, not biological replication.
Q1b/Q2b are completed exposed development; Q3b completed with no passing budget.
A separately justified target-source learning procedure and budget are still needed.

Run with `.venv/Scripts/python.exe`, one numerical CPU thread, 1,800 seconds wall
and CPU, 1 GiB peak RSS, 100 MiB outputs. Check resources every 4,096 rows and at
stages; Windows `peak_wset` supplies lifetime peak rather than only samples.
Checks are cooperative, not hard OS enforcement. Bounded requests can delay a
check by at most their timeout. Record actual wall/CPU/peak/transfer/output sizes,
test commands and failures. Refuse overwrite and registered-byte drift.
The registration is a local timestamp/hash binding, not a prefit Git commit.
