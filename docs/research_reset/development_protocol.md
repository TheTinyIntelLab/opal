# Exploratory development protocol

This registration asks whether pair-specific residual structure in Horlbeck's growth measurements predicts a different deposited infection replicate for unseen pairs of supported genes. It reuses an exposed source and the existing pair split. Neither the source, split, infection replicate, nor results provide untouched confirmation. This protocol is frozen before the new fits, after the prior study and external failure were known.

Use exactly the prepared bank and canonical 60/20/20 assignment identified by `results/fitness-20261020/protocol.json`. Keep all guides, orientations and both infection replicates for each pair in the same split. Require distinct, unique canonical pairs, train-supported genes, finite outcomes, pair counts at least four and single counts at least twenty in both contexts and infection replicates. Do not add magnitude filters or impute missing outcomes. The original preparer and acquisition receipts define the deposited source and attribution. Raw measurements and numerical checkpoints remain local.

Run two directions. Train using infection 1 responses and singles, validate on infection 1, then score test pairs on infection 2; repeat with infections reversed. The alternate infection's pair responses are never a fitting or selection input. Both directions use the same pairs, so they are dependent sensitivity analyses rather than independent replications. Measured target-context singles are available for training only from the source infection. No external cohort enters this experiment.

For each direction fit zero, additive, minimum-single, calibrated-single ridge and node-effect ridge references with fixed alpha 100. Choose a reference separately for each cell context using source-infection validation MSE. This is the full reference menu; report every reference's test MSE even if validation chooses poorly. Fit one independent-context symmetric rank-8 residual completion, penalty .01, 500 Adam steps, seed 20261022, using the existing implementation and training-only response scales. Choose the step using source-infection validation every 25 steps. This is a fixed diagnostic configuration, not a rank or penalty search and not a novel architecture.

Fit one negative control with the same configuration and a fixed shared permutation of training residual pair labels. Preserve cross-context residual covariance but destroy training pair-to-residual alignment. Use real source-infection validation for this control too. This is one falsification check, not a permutation significance test. It cannot prove the absence of signal if the aligned model fails.

Primary outcomes are raw held-pair MSE on the opposite infection and paired MSE differences relative to the validation-selected reference, separately in both contexts and directions. Report same-infection test MSE, all baseline MSEs, residual replicate Pearson correlation and cross-product as secondary diagnostics. Also score minimum and additive predictors using target-infection singles as an explicit extra-information diagnostic after selections freeze; neither enters selection nor candidate fitting. Residual cross-products do not isolate biological interaction because shared guides, single references and processing can create correlated errors. Do not call replicate differences an irreducible biological noise floor.

Use 2,000 seeded positive node-multiplier draws. Give each gene one independent Exp(1) weight and each pair the product of its two endpoint weights. Compute the weighted mean paired loss difference and percentile 95% bounds. This preserves shared-gene dependence in a conditional dyadic sensitivity analysis; it does not estimate between-culture, between-source or study-level uncertainty and supplies no formal population coverage guarantee. Cell contexts and the two infections are not four independent scientific replications.

The development gate requires at least 2% lower cross-infection MSE than the chosen reference, upper paired node-multiplier bound below zero, and lower MSE than the shuffled model in every direction and context. Passing authorizes only a subsequent untouched-source experiment. No architecture is promoted from these reused data. Failure ends this fixed completion diagnostic without rescue tuning and directs effort to reference quality, residual reproducibility or a different target. No post-result exclusion is permitted.

Before fitting, freeze protocol/code/data/split hashes, run executable synthetic tests, persist their exit code, output and hash with UTC timestamps, and require a passing receipt newer than registration. The run writes a start receipt before its first fit and a model-selection receipt before computing test metrics. Refuse overwrite, code drift and data drift. Use one CPU worker, at most 1,200 wall seconds and four neural fits. Replay each saved model and the final composite predictions exactly. Record deviations instead of changing this registration after outcomes.

Commands are `python tools/reset_development.py freeze --data <prepared> --prior-assignment <fitness-v1/assignment.npz> --output results/research-reset-development`, followed by the same tool's `verify`, `run` and `replay` actions with `--output results/research-reset-development`. The executable prerequisite suite is `python -m pytest tests/test_reset_development.py -q`.
