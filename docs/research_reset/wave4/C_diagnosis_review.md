## Corrections and limitations for A

1. legacy_all_variant_interval_intersection currently covers reference plus numeric chunk sizes only. row_min/row_max are not updated for permuted_inverse, reversed_orientation or noncontiguous, and repeated queries have different occurrence lengths. Rename it to numeric-partition interval intersection or include aligned occurrence variants. Its false result here is already enough to reject all-variant compatibility, so this omission does not reverse the current negative result, but a future true result would overclaim.

2. The result proves amplification by small saved scales, not by hitting the 1e-8 floor. The reported dominant columns have scales about 1.03e-5 and 1.73e-5, and the largest standardized discrepancy uses about 3.10e-6. Do not call floor clipping the measured cause. The trace supports batch-shape-sensitive kernel-whitener multiplication followed by small-scale standardization on this stack. It does not identify the internal OpenBLAS microkernel or establish a platform-independent boundary pattern.

3. The promised full identity metadata is narrower in code. Node semantics are not explicitly asserted between old and transform; ordered gene names are hashed and length checked, not independently recovered from a second checkpoint schema. np.array_equal checks numerical values without requiring equal dtype. Metadata lists only six fields and omits byte order and explicit contiguity, and center_rows mapping is checked for old but not separately for transform. With exact bank/registration hashes and exact map arrays this is not an alternative explanation of the observed reproduced error, but describe these as custody-derived identity and checked numerical equality rather than a complete schema/dtype validation. No replacement strict loader is implemented here.

4. The saved-state command contains no fixed-state synthetic check, despite synthetic permission and the plan. Resource guards are correctly called cooperative, and peak RSS uses Windows peak_wset. Output-cap checking covers final result size rather than all sidecars, which are small here; before arithmetic, start binds script digest and inputs sidecar binds artifact digests. Main cannot itself interrupt an unreturned BLAS operation, so retain caller timeout evidence when reporting enforcement. Installed replay must still be inspected independently.

5. Treat the initial preserved diagnostic as completed N1 with a rejected candidate, not a failed command that needs rerunning to become green. No helper is accepted. Any implementation revision for receipt/reporting should preserve the current code digest, starts and result and get root direction before another real-state run. Do not tune contractions against this exposed vector.

## Minimal independent fixed-state regression proposal

Use an explicitly populated FlexibleSingles instance without prepare/solve/fit: two or three supported genes, float64 singles, 64 fixed centers, positive bandwidth, a hand-set 64-by-64 whitener with alternating large columns, zero center, a small positive scale on one nonlinear coordinate, and one nonzero coefficient there. Query a repeated supported pair 2049 times, compare a singleton, full chunk and tail occurrence, then permute/invert. Keep an ordinary nonlinear coordinate with unit scale/nonzero coefficient in a second control so suppressing nonlinear output cannot pass. Hard-code state or derive it from a fixed array formula, never select it with biological losses.

For a deterministic portable test of amplification, inject a known small perturbation into one already computed whitened coordinate, hold all later operations fixed, and assert its signed prediction change equals delta/scale times coefficient within the unchanged 1e-12 gate. This tests the causal arithmetic independently of whether a particular BLAS version reproduces a shape-sensitive dot. A separate unasserted/environment-qualified real-matmul probe can demonstrate boundary sensitivity; do not make a platform-specific nonzero error a universal test requirement. Use the saved-state N1 receipt as the actual environment-specific reproducer. If an adapter is later proposed, it must independently pass frozen compatibility and its own invariance; an injected perturbation test alone cannot validate it.

Decision: accept the N1 design and observed result as engineering diagnosis, with reporting corrections above. No accepted repair, no scientific successor, and no authorization for completion fitting or held-test scoring.
