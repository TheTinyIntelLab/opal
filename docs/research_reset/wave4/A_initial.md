## Competing hypotheses and distinguishing tests

1. Prediction batches change Nystrom matrix-product arithmetic. Historical predict maps the queried validation subset in chunks of 2048, while v2 maps the whole pair population and only then selects validation rows. Compare identical keyed rows stagewise: sorted singles, normalized coordinates, distances, kernel, whitened features, concatenated design, standardized design, linear contribution and final additive assembly. Record first nonzero difference, maximum location, row identity, column and scale/coefficient amplification. If coordinates/kernel match but whitened features differ by row batch shape, this supports shape-dependent matrix multiplication. A difference before whitening instead implicates indexing or coordinate evaluation.

2. Ordering or feature identity is wrong despite compatible shapes. Verify saved ordered gene/pair schema, split indices, supported queries, center rows, all transform arrays and model scalar state. Compare feature blocks and gene one-hot placement, reversed orientations, selected/reordered validation rows and inverse permutations. Identity before standardization rules this out for inspected rows; mismatch means stop interpretation until custody/alignment is resolved.

3. Nearly constant map columns amplify roundoff through the 1e-8 scale floor. Hold saved center/scale/coefficient fixed, report per-column raw error, standardized error and weighted contribution; compare floor-hit and non-floor columns. Controlled perturbation and a hand-constructed fixed-state synthetic case can distinguish amplification from a coefficient mismatch. Do not recompute training moments or change the scale floor as a rescue.

4. Final matrix reduction, dtype, strides or addition order causes remaining error. With identical cached features, compare historical query chunks, global-map chunks and row-local contractions at sizes 1, 2, 63, 2047, 2048, 2049 and full validation. Capture dtype, contiguity, NumPy/BLAS versions and one-thread runtime. Compare C/F contiguous operands and historical additive-plus-offset assembly. If cached features are identical but projections differ, whitening alone is insufficient. Addition-order errors near machine precision cannot explain larger discrepancies unless intermediate cancellation is demonstrated.

5. Fitted state or environment is actually different. Hash exact saved inputs before and after, assert array equality rather than infer it from prior audit, and run the same saved-state diagnosis through the installed package with checkout imports excluded. A changed digest, imported checkout, missing artifact or state mismatch is a no-go, not permission to refit. Thread-dependent or platform-dependent behavior limits any portability claim.
