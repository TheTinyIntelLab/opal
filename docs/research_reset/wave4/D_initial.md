## Competing explanations and discriminating tests

1. **The design supplies a valid supported-gene task.** After root freeze, inspect only separately identified response-free guide/construct and sample metadata. Build ordered construct identities including exact spacer sequence, target identity, transcript/exon annotation if supplied, and promoter/vector arm. Each held distinct gene pair must retain local training support for both genes and the exact arm-matched gene/scramble references. Expected result is a dense eligible graph with auditable losses. Missing arm-matched controls or an ambiguous ordered key means no-go for those constructs, and possibly the whole primary. A 73-node design is not a measured coverage result.

2. **The apparent singles are contaminated by held doubles.** Trace every reference input to explicit gene/scramble measurements, with scramble/scramble controls supplying the centering reference. On synthetic fixtures, alter every held-double outcome while holding controls fixed. Reference features, eligibility, transforms and predictions derived only from singles must remain invariant. If author-fitted probe scores or their rank weights change, that confirms leakage and they must be excluded rather than relabeled as measured singles. Do not replace a missing single with an all-partner estimate.

3. **The endpoint is a reproducible growth slope rather than an inherited gamma.** Register an assay-specific log-relative-abundance slope and its units, permitted time points, pseudocount/zero policy, centering, missingness and aggregation before response access. Confirm whether a control-ratio slope can be computed without fitting global held-double fitness. Synthetic proportional growth should give the known slope; multiplication by sample-wide depth should cancel under the specified reference transform. An endpoint that needs held-double population fitting or undeclared normalization fails the identical-information contract. The published kinetic procedure cannot simply be imported because it jointly models population composition. Day-three survival selection must be disclosed, and zero later counts must not become outcome-dependent exclusions.

4. **Two replicates are separate initiations rather than split cultures.** Obtain a response-free lineage map from transduction through culture, passage, harvest and sequencing. Expected result is documented independent infections with time points nested inside each infection. A manuscript claim alone is insufficient; split cultures permit within-initiation sensitivity checks only. If lineage remains unavailable, any future experiment must explicitly limit replication claims, and cannot pass a gate requiring independent initiation.

5. **The evaluator remains correct under a different assay.** Before any new response access, B should exercise synthetic count/time fixtures for exact-arm matching, explicit control roles, key uniqueness, missing samples, fractional versus integer inputs as appropriate, nonfinite values, zero late counts and aggregation order. Predict each construct first, average eligible constructs equally within culture, then cultures equally, and score canonical pairs equally. All orientations and guide variants of a pair share a split. A deliberately swapped arm/time/replicate must be rejected, not silently joined. Reference and completion interfaces must expose identical allowed measurements, with TRAIN-only learned transforms and VALIDATION-only selection. A passing generic evaluator is insufficient if the source adapter violates these conditions.

## Prospective decision and limits

Go now only for literature and, after an explicit root freeze, response-free metadata qualification. No-go now for Shen response access, headers, scientific completion fits or scoring. Every gate must pass independently: item-specific rights, ordered keys, exact guide/arm singles and control roles, sample/time and initiation provenance, frozen endpoint/QC, leakage-safe equal-information evaluator, full-design resource feasibility, and a feasible source-local label budget. Charge the actual unique train-plus-validation pair union separately from singles and controls, with reuse explicitly counted. A budget from the failed original 5,000/20,000 experiments is not validated for this source.

If root later approves a separate scientific successor, bind code/input hashes, source-specific splits, endpoint, reference menu, budget and stopping rules before access. Preserve the historical 5% paired MSE gate, all-reference veto, replicate checks and three shuffled controls unless a separately justified prospective question explicitly changes them. Conditional gene bounds remain conditional, not population confidence. Retain the 1e-12 replay gate and stop on failure; no arithmetic diagnosis here authorizes completion fitting.

Successful prediction would establish adapted local completion among measured supported genes in a knockout growth assay. It would not establish frozen-weight CRISPRi transfer, cold-gene prediction, biological interaction identification, virtual-cell performance, or assay savings. Pair-specific technical effects can reproduce low-rank predictability. A strong-reference loss would reject the tested completion advantage; a metadata failure would reject qualification under this contract, not the biological source itself.
