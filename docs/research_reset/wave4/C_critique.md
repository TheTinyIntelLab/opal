# C critique of A initial numerical proposal

A's proposed saved-state stage trace is a sound engineering next step, conditional on root freeze. I do not yet accept batching as the diagnosis or either replay candidate as a fix. No experiment, test, fit, scoring or project-code import was executed for this review. C_independent_notes.md was written before reading A_initial.md and remains preserved separately.

## Evidence and objections

The strongest evidence is equality of fitted coefficient/center/scale and the reported matching Nyström state, alongside a roughly 1.2452e-8 validation prediction mismatch. It excludes neither query/schema mismatch nor omitted state differences. A correctly proposes a full identity check. Make the inventory explicit: singles, ordered gene schema, validation indices and pair keys, support, input_center, input_scale, centers, whitener, bandwidth, center, scale, coefficient and offset versus mean, with shapes/dtypes and the mapping from Q2b chosen index to alpha. center_rows equality alone is insufficient when the training-row universe differs. The installed verifier checks only three numerical arrays, so it does not independently establish the entire receipt's claim.

Static code supports two different batch partitions. v2 mapped_features builds features on consecutive global-bank rows, whereas historical predict builds them on the selected validation query. The kernel computes subtraction/square/sum explicitly; its whitening is the matrix product most directly exposed to a batch-shape change. A tiny raw whitening discrepancy divided by a 1e-8 feature scale could plausibly reach 1e-8 predictions. Plausibility is not causality, and a raw feature delta without the weighted standardized contribution cannot establish that it explains the final delta.

The current synthetic equivalence fixture has 120 total rows and 20 validation rows, all below 2048, and fits its state. Its pass neither covers the boundary nor meets this wave's no-fit requirement. New engineering tests must use explicit fixed state or saved state. Do not run the existing fitting tests as a general regression command during this task unless root separately expands authorization. A full-suite command can contain prohibited fits even when described as a delivery check.

A's two candidate obligations may conflict. Historical query-chunk outputs can themselves vary under caller batching or permutation. If historical predictions for the same keyed row differ by more than 2e-12 across partitions, no single invariant result can lie within 1e-12 of both. Even smaller differences need the actual interval intersection checked. Specify which frozen historical validation vector is the compatibility target and measure historical self-consistency first. Never redefine the target as whichever legacy call shape agrees with the candidate. Candidate A is a reference-path control until it independently passes invariance. Candidate B is an arithmetic alternative until it independently passes historical compatibility. Neither passes by construction.

## Distinguishing tests after root freeze

1. Identity and custody first. Use registered saved K562 fold-zero state, exact validation indices and existing singles/pairs. Verify file digests and every prediction field above before arithmetic. Expected result is exact identity, including offset/mean. Any failed identity makes an arithmetic explanation premature; stop and report the mismatched field. Input loading should name allowed bank fields and avoid inspecting response arrays or any test prediction file. Reading whole-file bytes to verify an existing hash is separate from accessing its outcome arrays.

2. Reproduce and localize. Evaluate legacy validation-query chunks and legacy global-bank-map selection with the same state, then compare sorted singles, coordinates, distance, kernel, whitened columns, full features, standardized features, dot and final sums. Expected result under the leading hypothesis is identity through kernel, first divergence at whitening, followed by amplification in small-scale columns. Divergence before whitening instead points to keys/inputs or coordinate arithmetic. Identical features with unequal dots implicate the final contraction. A different final delta from the historical receipt is still evidence, but requires environment/path reconciliation before claiming reproduction.

3. Causal swaps, not correlation. Hold the final projection/addition path fixed while swapping only globally mapped versus query-mapped features. Then hold features fixed and swap only projection layout/reduction and additive grouping. Record whether each swap reproduces or removes the mismatch, and report any remainder at the exact gate. The historical sum is (singles_sum + offset) + dot; v2 is singles_sum + (mean + dot). A stage maximum is insufficient because extrema can occur on different rows. Record the same worst row's contributions and per-column deltas, preserving cancellation rather than summing absolute maxima as though they were the prediction error.

4. Minimal boundary and permutation checks. Include 1, 2047, 2048, 2049 and full-validation queries; repeated rows placed in both full and tail chunks; a reordered query followed by inverse permutation; reversed gene orientation; and noncontiguous inputs. Each compares values by pair key and occurrence, so repeated queries are not lost in a dictionary. Use C/F layout controls with identical values/dtype. Expected invariant output is at most 1e-12 absolute difference with rtol=0. A tail-only failure supports a shape-sensitive kernel selection, while reordered-only failure can expose positional batching or alignment. A passing local matrix of cases bounds the claim to those cases and environment.

5. Fixed-state synthetic controls and installed replay. Construct near-constant whitened columns, scale-floor amplification, cancellation and ordinary well-conditioned controls without prepare, solve, fit, penalty selection or outcome losses. An independently designed case should fail the old inconsistent path and pass the adapter. Also preserve a normal case so a fix cannot pass by suppressing all nonlinear contributions. Installed replay must assert actual module paths, use the bound source bytes, disclose dependency reuse and repeat the identical no-fit replay twice as root proposes. If a clean, invariant contraction misses the frozen vector by over 1e-12, stop rather than choose higher tolerance or a new transform.

## Limits and decision

Go for a frozen saved-state/synthetic engineering diagnosis only, after A's revision specifies the immutable historical target, complete identity fields, causal swaps, no-fit command scope and exact resource caps. Root's freeze should resolve A's 300-second/25-MiB proposal versus root's 15-minute/256-MiB maxima and bind the actual command. No automatic retries on failure or cap exhaustion. Post-freeze implementation review should reject edits to frozen modules, new whitener decompositions, changed scale/eigenvalue floors, dropped columns or recalculated training statistics.

An engineering pass requires reproduced mismatch, localized causal explanation, unchanged-state 1e-12 compatibility, caller-batch/permutation checks, independent fixed-state controls and installed replay. A failed obligation is no-go with preserved evidence. Passing these checks authorizes an engineering report only. Completion fits, scientific continuation, penalty selection, and held-test scoring remain prohibited without separate explicit root successor approval. No new source outcomes or reserved SPIDR response headers are authorized. One saved fold on one NumPy/BLAS stack cannot establish portability, biological interactions or independent-source prediction.
