# Independent root proposal

Written before worker proposals or diagnostic execution, 22 October 2026.

The strongest-reference question remains unanswered. Identical fitted state
narrows the search but does not establish identical inputs or arithmetic. I
propose a read-only stage trace, followed by a versioned prediction adapter only
if the first divergent operation is reproducible and causally isolated.

Competing explanations are row/key mismatch, global versus query-local feature
batching, floating-point contraction in matrix products, dtype or layout changes,
and addition order after the standardized linear prediction. Compare indices,
singles, sorted coordinates, kernel matrices, whitened maps, standardized maps,
dot products and final predictions separately. A direct query-local feature path
versus the existing globally precomputed path distinguishes batch-dependent
whitening from incorrect stored coefficients. Holding features fixed while
changing only addition order distinguishes cancellation from reassociation.
Thread and layout controls must not substitute for locating the first divergence.

Success requires reproducing the historical discrepancy without refitting,
matching the exact frozen baseline at absolute tolerance 1e-12 with zero relative
tolerance, and independently designed tests that fail for the old path and pass
for the proposed adapter. Synthetic adversarial cases should include nearly
constant coordinates and amplified whitening. Replay twice and from an installed
wheel. Preserve the old evaluator and all v1/v2 bytes. If the discrepancy cannot
be isolated, stop without a biological interpretation. Even an explained fix
does not authorize another scientific run until A and C agree and a separate
registration binds unchanged population, comparison, thresholds and budget.

For sources, a conjunction of endpoint semantics, key mapping, rights, matched
singles, controls, evaluator support and defensible units must pass. Public
availability does not establish rights. Design counts do not establish observed
coverage. A paper's replication language does not establish independent
initiations. Qualification can legitimately finish blocked. No reserved response
table, header or new source outcome may be opened. Metadata fixtures must
include malformed or ambiguous mappings and prove rejection rather than merely
assert a positive report. No source-local budget can be justified from designed
pair counts alone.

Allow at most 15 minutes per numerical diagnostic, 2 GiB peak memory and 256 MiB
new diagnostic output, with a 1 GiB writable-volume reserve. Keep full numerical
arrays outside Git. Metadata checks are CPU-light and can run concurrently;
serialize numerical and delivery jobs. Record actual resource measurements and
every failed command. Root will review the revised worker plans adversarially
and freeze exact execution commands and input hashes before allowing diagnostics.
