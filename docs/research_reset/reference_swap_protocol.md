# Frozen correction with local singles

This is an exploratory successor diagnosis after the historical external outcomes, the earlier reset diagnostics and the cross-infection development fits were known. It tests a new hypothesis chosen with those results exposed. It is not adapted-model external validation, independent confirmation or a promotion experiment.

For each of the four historical cohorts, reuse its exact absent-original-eligible-bank panel with both assay-local singles measured, identified by canonical gene names and the historical frozen row assignment. Keep the existing completeness exclusions and no further coverage, gene or magnitude filter. Reuse the verified external prepared-v2 banks and unchanged historical prediction arrays. The existing `panel` validator rejects nonfinite outcomes, duplicate identities, noncanonical pairs, invalid coverage counts and misalignment. No numerical source arrays are redistributed.

Define the old learned correction as the historical completion prediction minus the historical main-effect prediction for the same row. Never infer it from an observed external pair residual. Its unit coefficient is fixed. Compare assay-local minimum singles against minimum singles plus that old correction, and assay-local additive singles against additive singles plus that correction. This swaps the reference while retaining the original model's unchanged residual output. It requires additional assay-local single measurements and is a successor diagnostic, not the original zero-shot model.

Primary scoring averages the two infection-specific minimum predictions, or the two infection-specific additive predictions, and compares this average with the average pair target. Do not take the minimum after averaging singles, which can differ from the average of infection-specific minima. Add the same historical correction to either average reference. Secondary scoring uses infection 1 singles against infection 2 pair targets and the reverse, retaining that same fixed correction. These directions and cohorts share genes, reagents, processing and lab lineage; never treat them as independent studies.

For every reference, cohort and scoring direction report MSE, MAE, bias, Pearson correlation and relative MSE change; report candidate-minus-reference paired squared-loss differences with 2,000 gene-resampling draws, seed 20261022. Resample unique genes with replacement, give each pair the product of endpoint multiplicities, discard zero-weight draws and record retained draws. This reuses the earlier reset's exact uncertainty function. Intervals are conditional gene-dependence sensitivity diagnostics with no formal population coverage guarantee, no culture/study uncertainty and no multiple-comparison significance claim.

Also report centered correlation of the old correction with the local target-minus-reference residual, their means, standard deviations, quantiles and RMS magnitudes. Do not fit a scale, search correction weights, select checkpoints or retrain any model. Positive/negative correlations distinguish alignment; magnitude mismatch can explain harm despite positive correlation. These descriptive comparisons cannot uniquely isolate biological interactions, and reference replacement alone cannot rule out reagent or protocol shifts.

There is no model-promotion gate. A lower mean MSE with a loss-difference interval below zero is evidence only for that conditional comparison, and a mixed or negative result rejects a simple universal reference-replacement rescue. Report all comparisons, including negative ones, without selecting an endpoint or source based on the best result.

Before any new swap scoring, freeze this protocol, implementation, tests, imported diagnostic code and all numerical inputs. Run the synthetic prerequisite suite after freezing, record its output/exit code/code hashes and timestamps, then require that passing receipt before `run`. The run writes a start receipt before loading/scoring the new combinations. Refuse overwrites and any code/data/protocol drift. Recompute the full scientific aggregate JSON for exact replay. Record wall time and peak process RSS after scoring, check against 600 seconds, 2 GiB and 16 MiB aggregate output, and use one numerical thread. These are post-run checks rather than an interrupting resource monitor.

Commands use `python tools/reset_reference_swap.py freeze --output results/research-reset-reference-swap`, then `verify`, `run` and `replay` with the same output. The default input locator is the preserved `results/research-reset-diagnostics/protocol.json`; its local numerical paths and the original historical hashes determine the source bytes. On another machine reproduce the licensed acquisitions and preparation and provide an input-locator protocol with matching original input hashes, rather than silently substituting a dataset. Keep historical registrations unchanged.
