# Q2b fixed flexible singles comparison

Prospective development protocol, 21 October 2026. This tests whether a fixed nonlinear function of the existing gene-level singles can account for the prior completion advantage. It changes no source population, target, scalar-single input, Q2 assignment or prior checkpoint. All six sources and historical results are exposed development evidence. No new independent-source or biological interaction claim follows this experiment.

Q1b must first pass its identity/control-matching integrity checks, sum commutation and exact replay. Q1b's exact-guide eligible panel can have missing pairs or different construct weights. Those findings block guide-aware equivalence/refits and are reported as diagnostics. They do not alter Q2b's original gene-level targets or remove any query pair. This dependency distinction is specified before Q1b outcome diagnostics. An integrity or replay failure stops Q2b, rather than bypassing it with a different panel.

## Frozen model and selection

Use the original six scalar banks and all thirty Q2 fold assignments. Fit training outcomes only. Sort the two measured single effects for symmetry, calculate their two coordinate means and standard deviations on training pairs, and floor standard deviations at1e-8. Choose exactly64 training-row centers without replacement using NumPy default_rng seed20261022. The fixed bandwidth is the median nonzero Euclidean distance among unordered center pairs; no nonzero distance is a stopped branch. Use exp(-distance_squared/(2*bandwidth_squared)). Whiten the center kernel by its eigendecomposition, flooring eigenvalues at1e-10. The map is a fixed RBF Nystrom approximation, not a learned architecture or bandwidth search.

The phenotype-only design concatenates this64-column map with the existing three symmetric single features, sum, absolute difference and product. The node design adds the same additive gene incidence as the old ridge reference. Both use additive singles as an offset, an unpenalized residual intercept, and training-only feature centers/scales. Fit ridge penalties1,10,100,1000 on identical training rows. Each family chooses its first minimum shared-validation MSE in ascending penalty order. An additional prespecified flexible policy chooses the lower validation minimum of these two families, with exact ties preferring phenotype-only. Save every penalty checkpoint, all validation losses and all thirty family/policy choices before any new test scoring.

No residual operator is refitted in Q2b. Compare with the exact original Q2 selected-simple and rank-eight predictions on the same full test indices, including all originally eligible pairs. This tests functional misspecification without confounding it with new residual fits. A residual refit against a stronger nuisance function needs a separate prospective registration, as required by the authoritative plan.

## Metrics and scientific decisions

Primary loss is equal-canonical-pair MSE on mean infection targets, separately in every task. Report phenotype-only, nodes and validation-selected flexible policy alongside the frozen simple/completion scores. Secondary outputs are MAE, bias, centered Pearson, target variance and each infection-target MSE. Never pool raw losses across tasks or call the six overlapping tasks independent studies.

Use the existing paired endpoint-multiplicity gene bootstrap,2000 draws, seed20261022, with empty-draw counts and leave-one-gene-out sensitivity. These bounds condition on the observed gene panel and are not independent-culture confidence intervals. Report all comparisons, including failures and near ties.

Two distinct screening decisions are fixed before fitting. A phenotype-only function conditionally matches the completion ceiling if the upper paired bound for phenotype-minus-completion MSE is at most2% of completion MSE in every task and both infection-target point losses are within2%. This is a practical conditional noninferiority diagnostic, not population equivalence or proof that interactions are absent. Completion retains a robust residual advantage only if it improves on the validation-selected flexible policy by at least5% in every task, its upper paired bound is below zero in each, and neither infection loss worsens. If neither all-task criterion holds, the conclusion is mixed or insufficient, not an architecture promotion. A remaining gain against a64-center function class still cannot identify molecular interactions.
