# Original-source reagent diagnosis is feasible before SPIDR

Metadata audit, 21 October 2026. The existing Horlbeck files retain enough identity structure to propose an exact-guide, arm-matched single-effect diagnosis on exposed outcomes. This is feasible in principle, not an executed construct-level evaluation. This audit read the 36 KB guide library, three phenotype headers and six initial pair identities; it did not scan the full phenotype table, convert response fields, calculate new outcome statistics or fit models. SPIDR responses remain unopened. `plan.md` owns any decision to execute the proposal below.

The guide metadata has no transcript accession or intentional mismatch annotation. A name contains a gene symbol, strand and site-like identifier, but these do not establish a specific transcript. All sequences being 20 nucleotides long does not establish perfect matching to a reference genome. Within-source matching can preserve the same exact name and sequence without inferring either annotation. Missing annotations must remain explicit; they cannot be filled with invented transcript IDs or perfect-match flags.

The guide library contains no context or infection columns. Those identities come from the phenotype table. The existing primary mode uses zero-based columns 13/14 for K562 and 4/5 for Jurkat, all `Triple Sequencing`, `Replicate 1/2`. Columns 15/6 contain published replicate averages and must not replace the individual measurements. Other sequencing modes describe alternative readouts of these screens, not new cultures. The bounded six-pair identity sample joined to guide metadata, but full join completeness and finite exact-single coverage remain unmeasured.

## What the current preparation discards

[prepare_fitness.py](../../tools/prepare_fitness.py), SHA256 `6ab2c2c5f086cc568253ae4aec444914dedf1f779e31bb3cb93a08f624de7558`, reduces every guide name to its first underscore-delimited gene token. It pools every target-guide/negative-control construct for a gene within context/infection, and pools reciprocal orientations and guide combinations for each distinct-gene pair. It then requires at least 20 single observations and four pair observations in every context/infection. The frozen bank preserves counts and infection means, but loses the identities and weights needed to reconstruct exact-guide singles. Those must come from the original table, not the NPZ.

The official author code supports preserving the missing structure. `generatePhenotypeMatrix` separately computes position-A and position-B guide single means against opposite-position negative controls; `abbaAveragePhenotypes` is a later optional orientation average. The count reader writes ordered A/B identifiers and distinguishes upstream/downstream barcodes. Its allowance for sequencing-read mismatches is a read-mapping rule, not evidence of deliberately mismatched perturbation guides. [Pinned analysis code](https://github.com/mhorlbeck/GImap_tools/blob/601cd22126432edadb30202e952859195c73a841/GImap_analysis.py), [pinned count reader](https://github.com/mhorlbeck/GImap_tools/blob/601cd22126432edadb30202e952859195c73a841/tripleseq_fastqgz_to_counts.py).

The verified author-code HEAD is `601cd22126432edadb30202e952859195c73a841`. Retrieved source SHA256 values are `038c3854a05b846f240ff3d754c63c11a42c339d46f83a0e1a10ffbba9e74821` for `GImap_analysis.py` and `4cc839063f557f568fa6987dcfae3ef209b7ed34cbc455e65bf6b7f7ae86858a` for `tripleseq_fastqgz_to_counts.py`. Only code was retrieved, with no counts or new biological source data.

The processed table already supplies construct-level gamma. It does not supply T0 coverage or enough information to recompute gamma normalization independently. The author processing code centers double-negative controls and divides by doublings, with upstream filtering. A successor must preserve this provenance rather than call gamma raw counts or claim to undo source filtering. Published globally fitted interaction scores are unnecessary and should remain excluded.

## A narrow proposed registration

First register an identity and availability pass. Preserve literal ordered guide IDs, sequence, arm A/B, context and infection. Annotate the 18 controls through the reviewed metadata names. For guide `g` in arm A, estimate its single from constructs `g++negative_control`; for arm B, use `negative_control++g`, always within the same context/infection. Average eligible opposite-arm controls equally and retain their identities/counts. Never substitute a different guide or arm. Report missing joins, missing measurements, duplicate constructs, control coverage and exclusions before outcome losses. A finite-single rule and minimum control support must be fixed in that registration. Full-table eligibility counts are not supplied by this bounded audit.

Then compare predictions on a single identical construct panel. For each ordered double, apply zero, sum and minimum to its two exact-guide singles, then average construct predictions within canonical gene pair/infection. Compare these with applying the same functions after averaging those same eligible construct-specific singles. This isolates averaging order: sum must commute under matched weights, while minimum generally does not. Compare the historical gene-single predictor separately, because its guide/control weights can differ even before applying a nonlinear function. Use the unchanged Q2 pair splits for reporting and keep every guide/orientation of a pair together.

This first comparison needs no new architecture or biological fitting. It can determine whether the apparent advantage over a gene-averaged baseline survives a stronger reagent-matched reference. It cannot establish that averaging explains the learned residual gain. Any follow-on refit of the existing rank-eight procedure against the reagent-aware reference needs a separate prospective registration, unchanged capacity, matching train/validation support and assignment-preserving controls. No failed Q2 gate is retrospectively repaired by that analysis.

Require synthetic tests before response conversion: exact guide/arm/context/infection matching, explicit missing annotations, control-only singles, exclusion accounting, duplicate rejection, grouped splits, sum commutation, nonlinear averaging order and deterministic replay. A processed-gamma adapter is needed. The existing [raw-count adapter](reagent_adapter.md) requires integer T0/T14 counts, transcripts and mismatch declarations; passing fractional gamma into it or weakening its frozen contract would be incorrect.

Use equal canonical-pair weights and paired gene-panel sensitivity bounds, retaining guide/control and orientation influence diagnostics. Shared controls and multiple guides remain dependent measurements, not new biological replicates. Restrict any direct Q2 comparison to the same eligible pairs and report population changes separately. These original contexts, outcomes and pair identities are already exposed, so every result remains exploratory. This diagnosis can improve the next SPIDR contract without consuming that source's response table.

The smallest next action is a frozen streaming identity/availability projector over the existing gzip with a modest CPU/disk cap, followed by review of exact-single support. No new download is needed for that step. Raw assets stay outside Git with source attribution; the original GEO-versus-author-deposit licensing caveat remains unchanged.
