# Architecture evidence, 20 October 2026

This is a source inspection record, not a forward plan. Official implementation inspection supports a specialized, strongly regularized combination model before a broad virtual cell model. Modern successes combine relevant intervention evidence, biological priors, and appropriate targets; the inspected sources do not establish that replacing a small correction model with a transformer solves sparse pair supervision.

## Sources and revisions

Official repository heads were resolved on 20 October 2026. TxPert and GEARS source files were inspected from shallow clones; CPA, PIE, and State were inspected through bounded official HTTP/API reads. No third-party implementation code or model weights were copied into Opal.

## TxPert

The [paper](https://www.nature.com/articles/s41587-026-03113-4?code=1&error=cookies_not_supported) explicitly tests Norman doubles with both singles observed. Its text describes the gain over additive Pearson delta as slight. Its best double model combines GO with proprietary PxMap and TxMap. Batch-matched controls and retrieval distinguish general stress from perturbation specificity. Split-half reproducibility is a comparison point, not an upper bound. MLP basal encoders won for unseen-single and double tasks, so foundation embeddings are not automatically advantageous. These findings justify careful measurement and relevant priors, not a claim that a public transformer will materially outperform Opal.

The [released configuration](https://github.com/valence-labs/TxPert/blob/08d82eea86746b044cf7531f4ec8c5f60e1cb73f/configs/config-exphormer-mg.yaml) uses latent width 64, decoder hidden width 512, four graph layers of width 128, batch size 64, and public STRING plus GO graphs with top-20 connectivity. It defaults to checkpoint inference. The [entry point](https://github.com/valence-labs/TxPert/blob/08d82eea86746b044cf7531f4ec8c5f60e1cb73f/main.py) supports baseline, inference, and prediction, downloads Zenodo record 15420279, and does not expose a training branch. Calling the released command is therefore not training from scratch.

The [model source](https://github.com/valence-labs/TxPert/blob/08d82eea86746b044cf7531f4ec8c5f60e1cb73f/gspp/models/txpert.py) sums perturbation embeddings into a basal latent state and decodes expression. Its configurable reconstruction loss mixes MSE and cosine similarity; the public config gives MSE weight one. It can use a VAE basal encoder, but the inspected config uses an MLP. The [README](https://github.com/valence-labs/TxPert/blob/08d82eea86746b044cf7531f4ec8c5f60e1cb73f/README.md) documents Python 3.12/CUDA 12.4, automatic cache downloads, public unseen-single and cross-cell-line checkpoint examples, and normalization to 4,000 counts with 5,000 HVGs. It gives no measured GPU-hours or memory budget. Exact double-model public reproduction is not established by this release.

## GEARS

The [official README](https://github.com/snap-stanford/GEARS/blob/f374e43e197b295016d80395d7a54ddb81cc6769/README.md) explicitly warns that training on singles alone does not reliably predict combinations and that the implementation is not designed for cross-cell-type transfer. Its example trains Norman using the simulation split, hidden width 64, batch size 32, and 20 epochs on CUDA. These defaults do not establish parity with Opal's split or information access.

The [model](https://github.com/snap-stanford/GEARS/blob/f374e43e197b295016d80395d7a54ddb81cc6769/gears/model.py) uses GO graph convolution for perturbation embeddings, coexpression graph convolution for gene representations, summed perturbation embeddings followed by an MLP, gene-specific decoders, and a cross-gene state module. Predictions add the input control expression. This supports order-invariant composition, but arbitrary interactions still require supervised constraints.

The [training implementation](https://github.com/snap-stanford/GEARS/blob/f374e43e197b295016d80395d7a54ddb81cc6769/gears/gears.py) uses Adam, a StepLR scheduler halving learning rate each epoch, gradient value clipping, and selects the checkpoint by validation MSE on DE genes. The [loss](https://github.com/snap-stanford/GEARS/blob/f374e43e197b295016d80395d7a54ddb81cc6769/gears/utils.py) actually raises residuals to the fourth power, with condition averaging and a sign-direction penalty. The sign operation has no useful ordinary derivative, so its explicit direction term should not be assumed to train a directional signal. Neither GEARS's DE-selected checkpoint nor its loss is equivalent to optimizing all-gene pseudobulk MSE. Peak memory and wall time remain unverified.

## CPA

The maintained [module](https://github.com/theislab/cpa/blob/fbd7c0250edc23eff003a10c99655579c53afd63/cpa/_module.py) supports Gaussian, negative-binomial, and zero-inflated negative-binomial likelihoods with a basal latent state, perturbation and covariate embeddings, and optional variational inference. Count likelihoods are meaningful only with compatible raw counts and normalization handling; switching a pseudobulk residual loss to NB without those observations is unjustified.

The [official Norman tutorial](https://cpa-tools.readthedocs.io/en/latest/tutorials/Norman.html) trains on 111,122 cells and 5,044 genes, uses raw counts, NB reconstruction, a nonvariational 32-dimensional latent, four 256-wide encoder layers, and two decoder layers. It uses adversarial disentanglement and mixup, sets a 2,000-epoch ceiling with early stopping, and shows about 39 seconds per epoch on an RTX A6000 in early logs. Only DUSP9+ETS2 and CBL+CNN1 are OOD; remaining validation cells are randomly selected from training conditions. That validation design is weaker than holding out complete combinations for model selection. A tutorial's expression R-squared cannot be treated as evidence of improvement on Opal's pair-level MSE.

## Newer, materially different directions

PIE is a particularly relevant October 2026 release. Its [README](https://github.com/ArcInstitute/pie/blob/21a526add9ff3a81b4f962d9b16bbae570052c63/README.md) describes a Perceiver IO model conditioned on curated knowledge, query-context control means, and response evidence from training perturbations and contexts. The canonical cross-dataset recipe trains on Tahoe, Jiang, ARC VCC 25, and Orion, then evaluates on Replogle using eight GPUs across two nodes. Within-dataset experiments distinguish unseen context, unseen perturbation, and both. The word combinations here means combinations of held-out factors, not proof of double-gene composition. It has a non-commercial share-alike license, so importing it would change reuse obligations.

The inspected [PIE model](https://github.com/ArcInstitute/pie/blob/21a526add9ff3a81b4f962d9b16bbae570052c63/src/pie/model/pie.py) has gene-query heads for DE, log fold change, and delta-p. Its [losses](https://github.com/ArcInstitute/pie/blob/21a526add9ff3a81b4f962d9b16bbae570052c63/src/pie/model/losses.py) combine class-weighted DE cross entropy, Huber log-fold-change regression, a differentiable direction hinge, and distribution-bin cross entropy. Thus its biological endpoint differs materially from predicting every expression value with equal weight. Evidence masking and response dropout are explicit components. An independently implemented, small evidence-conditioned estimator is a more feasible lesson than reproducing the full eight-GPU experiment here. No independent replication of PIE's claimed ranking was found in this inspection.

State's [official project announcement](https://arcinstitute.org/news/virtual-cell-model-state) describes attention over cell sets and training on more than 100 million perturbed cells. Its [current README](https://github.com/ArcInstitute/state/blob/9bbfe78a434a55205e4de834e1ea99f85f7a3add/README.md) supports separate embedding and transition models, HVG-space transition training, explicit zero/few-shot splits, and cell-eval. Its 40,000-step example is a recipe, not a measured compute budget. Set-level prediction is relevant if Opal later has raw cells and a distributional objective; existing population means cannot identify cell-level response distributions. The data scale and license terms make this a separate project decision.

## Recommendation and limits

The credible immediate hypothesis is that pair effects share a small number of response programs and can borrow strength through measured singles and shared targets, with shrinkage preventing weakly identified residuals from overwhelming additive predictions. Compare a low-rank or kernel pair estimator against additive, global correction, reduced-rank regression, and existing kernels using identical observed-single access. A graph or foundation representation earns inclusion only if it improves held-out pairs under the same locked protocol. A public KG is an additional information source whose provenance and ablation must be explicit.

For a future general predictor, PIE suggests pooled intervention response evidence and gene-level biological endpoints, while TxPert suggests public knowledge graphs and matched controls. Neither source supplies evidence that single-perturbation scale alone identifies arbitrary double interactions. Cross-context and unseen-target claims need separate held-out-context and held-out-target experiments, not renamed random-pair splits.

This inspection did not train the external models, verify their weight payloads, or measure their resource usage locally. It did not establish numerical superiority on Opal's protocol. External published metrics must not be inserted into a common leaderboard without harmonized preprocessing, splits, controls, and access to measured constituent singles.
