## Development improvements on 5 October 2026

A new closed-form symmetric residual-kernel procedure and a competitive selection
option are implemented. Three seeds per dataset and holdout protocol give 60 outer
fold evaluations for each procedure, with inner-fold selection and an expanded
25-configuration linear comparator. All 12 dataset/protocol/seed summaries show
positive occurrence-weighted gains, ranging from 0.83% to 3.98%. These are exploratory
development results informed by previously known historical test findings; partner
aggregation and the choice of linear control affect the conclusion. No new evaluator
responses were loaded. Checkpoints reproduce the saved unscored predictions through
the existing inference API. Cached single-bank kernel products reduce warm inference
to roughly 0.17--0.22 ms on this host. Tests now total 38 passing cases. See
`docs/improvement_study.md` and `results/improvements/summary.json`.

The manually supplied PertAdapt resources now pass restricted checkpoint loading,
unique gene ordering and mask dimension/finiteness checks. Download access is no
longer the blocker. Native model/training compatibility and an information-aligned
comparison remain unestablished; the current installation has CPU PyTorch, while
the published loader and distributed training script use CUDA.

## Architecture implementation on 5 October 2026

The six architecture priorities are implemented: joint reference uncertainty,
GO/Hallmark/GenePT/ESM2 fusion, structured output directions, bounded signal
weighting, independent Replogle single-screen transfer and strong residual
experts. Forty competitive outer folds retain the kernel instead of the neural
additions. Measurement-aware kernels complete three split seeds and matched
variance-permutation controls. Random-fold gains are consistent; partner gains
are mixed. External priors complete matched shuffled-identity controls, and a
frozen four-estimator TabICLv2 comparison completes on three dataset tracks.

A protected Wessels expansion preserves all original identity roles. Common-
population comparisons across three seeds show 16.05--17.60% random and
4.00--4.99% partner MSE reductions from additional eligible pair labels. With
measurement weighting the ranges are 18.73--19.54% and 4.08--4.99%. The broader
exploratory track had already exposed thirty protected query identities, so this
isn't independent confirmation. Full histories and both coverage exclusion
policies are retained.

The independent expression screen and PRESAGE archive downloaded successfully
and pass publisher MD5 checks. Encoder pretraining uses 2,002 mapped Replogle
single targets, with a held-out source-task target split. Its validation PC MSE is
0.87670 against 0.88021 for ridge and 0.90792 for the training mean. Source-scale
mean effects transfer only representation weights and output directions. Native
contextual backbone adaptation isn't covered by this experiment.

Linear controls now fit a converged convex gene-space objective after training-
pair feature scaling. Two interrupted fixed-optimizer tracks are preserved and
explained. The corrected transfer study is `transfer-v3`. The unified
`main.py frontier` command reproduces the amendment; the default research entry
point includes it after the historical batch. Numerical results, resource
lineage, identity exposure and inference timing are generated in the architecture
report, with paper tables and plots built from those artifacts.

The full regression suite has 67 passing tests, including bounded-feature extrapolation and checkpoint round trips. A wheel build and isolated-package
inference pass using the recorded scientific dependencies. Native GPU methods,
fresh confirmation, sufficient chemical coverage and human manuscript declarations
remain unresolved; these implementations don't establish frontier status.

The corrected transfer batch completes all four datasets and both holdout
protocols. No transferred head beats the kernel in an aggregate comparison. Large

## Joint uncertainty extension

Implemented and executed full shared-reference covariance kernels with safe checkpoint loading, three additional nested split seeds and identically searched covariance permutations. Sixteen technical draws per outer fit now recompute reference kernels and response coefficients. Subset-retuned learning curves and fitting/calibration/outer-validation error-radius diagnostics are complete on Norman, original Wessels and protected Wessels. Full-size controls share identical inner partitions in the corrected v2 curve track; the original reordered v1 remains preserved. These experiments expose limits rather than establishing frontier quality: covariance does not consistently beat diagonal weighting, both noise families worsen Wessels partner error on the new seeds, and protected partner 90% radii attain 83.7% observed coverage. Fixed-QC technical refitting still omits model selection and biological uncertainty. See `docs/ceiling_experiments.md` and `results/architecture/ceiling_report.json`.

The final extension passes 75 tests. The built wheel loads covariance checkpoints from an isolated package directory and matches current fitting predictions within 4.5e-14 absolute error on unscored query identities. The full `main.py frontier --skip-paper` build completes with the new stages included.
