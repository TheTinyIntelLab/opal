# Opal v1 documentation

Opal v1 supports assay-local combinatorial prediction under explicit measured-single and pair-label contracts. Start with the guides below; dated development records retain their original scope.

- [Installation](installation.md) explains package extras, supported Python and numerical dependencies.
- [Prediction and model availability](usage.md) describes growth and expression inference, abstention and checkpoint requirements.
- [Research findings](research.md) separates the six-task local benchmark from failed external transfer and negative experiments.
- [Reproducibility](reproduction.md) distinguishes public checks from licensed local biological replay.
- [Historical archive](archive/README.md) locates frozen protocols, original results and provenance.

The [paper](../paper/main.pdf) and [release notes](../RELEASE_NOTES.md) describe the v1 scientific scope.
