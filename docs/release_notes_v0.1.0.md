# Opal v1 research release, 0.1.0

Opal predicts population-mean responses to unmeasured intervention pairs from measured single effects plus a symmetric residual correction. This is an experimental research release of code, benchmarks, evidence, and two kernel references.

Kernels are the strongest tested family in exploratory development comparisons. Historical neural gains over additivity don't establish a robust pair-specific interaction advantage. Independent D-SPIN superiority and transferable uncertainty failed their gates; baseline-only learned state models lost to simple references. Those results remain in the release.

Assets include a wheel and source distribution, source archive, compact evidence, Norman and EmeraldBay kernel references, the manuscript, a commit/file manifest, and SHA-256 checksums. Raw datasets, external pretrained resources, Wessels/D-SPIN weights, and native third-party weights aren't redistributed. Dataset-derived model content uses CC BY 4.0; original Opal code is MIT.

Start with the README, `docs/release_models.md`, and `docs/release_evidence.md`. The synthetic quickstart checks execution and makes no biological claim. Full reproduction needs source downloads and track-specific dependencies.
