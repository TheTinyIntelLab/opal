# Frozen trained-model delivery

This delivery exposes already trained, validation-selected models from `opal-frontier-growth-v1`. It does not reopen that completed experiment or launch another fit. The original all-task promotion result remains a failure. COLO1 and other unqualified responses remain closed.

A separate [deterministic training reproduction](training_reproduction.md) was subsequently registered before fitting. It reruns the unchanged six fold-0 procedures and requires exact equality with every original saved state and vector. Its new fits are charged and reported separately; the export rule below and the failed scientific gate remain unchanged.

## Fixed export rule

Export fold 0 for every one of the six registered tasks, in the original task order. Fold 0 is a fixed deployment convention, not a comparison of test scores. Use exactly the `selected_policy` and its stored checkpoint hash in each original selection receipt. Do not refit, average folds, tune parameters, change singles, or select another model using exposed outcomes. Preserve the source checkpoint bytes and all historical files.

The bundle must bind gene names, stored source-local singles, support flags, selected checkpoint, task, fold, original registration, original selection and original fit inputs. Named-gene queries must reject unknown contexts, missing genes, self-pairs, malformed names and genes lacking two distinct TRAIN partners. Supported queries must exactly reproduce the original predictor. There is no cross-context transfer or cold-gene claim.

Existing predictions may be replayed for exact equality. Existing aggregate benchmark metrics may be copied with their original result hash and population definition. Those pooled five-fold metrics describe the frozen training procedure, not an independently evaluated all-data refit or the individual fold-0 checkpoint. No new test-based selection is authorized. This delivery will not fit a prediction-interval wrapper: validation already selected model checkpoints and configurations, and dependent pair residuals do not justify an unqualified coverage guarantee. The API must state that per-query calibrated uncertainty is unavailable; existing conditional gene-sensitivity intervals remain aggregate evidence.

## Custody and resources

Checkpoints and derived gene/single arrays remain in an ignored local bundle under `tmp/model-delivery-20261027/`. The historical local-reuse authorization does not authorize public redistribution. Commit code, source attribution, hashes, aggregate benchmark and receipts only. No biological checkpoint enters Git, wheel or sdist.

One numerical process may export/replay, with one numerical thread, a 600-second wall cap, 2 GiB sampled process-tree memory cap, 80 MiB new bundle cap and 1 GiB free-disk reserve. Stop rather than overwrite an existing output. Package installation reuses the host dependency closure and must be identified as such. A separately installed wheel must replay the delivered bundles outside the checkout.

Source investigation runs concurrently using primary, response-free documentary evidence. New source ingestion requires its own qualification and prospective registration; this export registration grants none. A blocked source does not prevent delivering the already trained, qualified historical research models, but it prevents claiming new biological confirmation or a newly competitive model.
