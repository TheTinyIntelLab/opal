## HAP1, Billmann and Costanzo 2026

The [author catalog](https://boonelab.ccbr.utoronto.ca/supplement/billmanncostanzo2026/) identifies query-screen metadata in File S1, library information in S2 and response matrices in S4. S1/S2 are not certified response-free: the descriptions include phenotype-related information. All workbooks remain unopened. The [Mendeley version-1 deposit](https://data.mendeley.com/datasets/bpcpfns6vb/1) explicitly declares CC BY 4.0. That establishes a useful deposit-level rights route, not byte identity with every author-hosted workbook.

The [primary Methods](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC13281610/fullTextXML) describe stable query clones challenged with a guide library. Cultures split after transduction provide technical replicates. Published qGI preprocessing selects guides using profiles across screens and removes components fitted to a global response matrix. Consequently, using the ready-made qGI matrix would allow held outcomes to influence training targets and eligibility under Opal's split contract. It is unsuitable for direct ingestion. Parental guide effects also do not establish exact single effects for each stable query clone. A valid task needs the raw-count/control and clone/sample join, followed by a prospectively bound training-safe endpoint. Query and library interventions cannot silently become a symmetric dual-guide task.

The publisher returned 403 and PMC returned a browser challenge. Root used the legitimate Europe PMC manuscript route successfully, without bypassing either service. Its 535,656-byte document hash and the exact request are in [the Methods receipt](../../results/model-delivery-20261027/hap1-methods-request.json).

The [Zenodo concept catalog](https://zenodo.org/api/records/15320010) resolves to record 20734737, version v1.0.4, and declares MIT. Its description explicitly says supplementary code **and data**. The named archive `GIN-v1.0.4.zip` is 687,231,851 bytes; it was not downloaded. The catalog links [csbio/GIN](https://github.com/csbio/GIN), whose visible directories describe downstream analyses. An archive title or software license does not prove a raw-count processing invocation or exact measurement lineage. The [catalog receipt](../../results/model-delivery-20261027/hap1-catalog-request.json) preserves the resolution and metadata hash. No fixed-version identity is inferred from the concept DOI.

The next useful source action is a bounded inventory of a documented raw-count and screen-mapping companion, then an outcome-free map and invocation audit. Directly fitting S4 would bypass a known leakage prerequisite, so this route does not yet authorize a biological fit.

## Yeast deletion and temperature-sensitive alleles

[TheCellMap's Costanzo 2016 catalog](https://thecellmap.org/yeast/costanzo2016/) documents strain identities, separately identified single fitness, double fitness and temperature. Its schema description is documentation, not an inspected table header. Native files remain unopened. Deletions and temperature-sensitive alleles require allele/condition identities rather than gene-only collapsing. This catalog did not establish an exact-item license or initiation/processing lineage, so it cannot yet qualify a new task.

No file or README was downloaded. The rendered landing page did not expose an item-level grant; root did not assign CC0 from the service name. Native allele/single joins, condition-specific preprocessing and initiation provenance remain unverified. Consensus profiles cannot replace raw eligible outcomes without their lineage.
